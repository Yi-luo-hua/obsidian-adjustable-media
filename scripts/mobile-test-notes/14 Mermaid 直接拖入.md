# Mermaid 直接拖入

在实时预览中，长按下面独立图表的正文约半秒，看到拖动图标后拖到图片布局边缘旁边；也可用右上角把手直接拖动。出现边缘投放提示后松手，完整图表进入布局，源位置不应留副本；一次撤销恢复两处。

```mermaid
flowchart LR
%% 保留注释、空行与完整围栏

    A[独立图表] --> B[直接拖入]
```

再拖一次，放到布局外，应取消且源码不变。从图表正文上下滑动应滚动页面；右上角源码按钮仍能编辑。

以下正文用于测试滑动。图表只出现一份，块外文字保持不变。

第一段：Android 手机和平板、iPhone 和 iPad 共用图表实现。

第二段：图表的缩进、注释和空行保持原样。

第三段：拖放只搬运整个围栏，不改写图表节点代码。

第四段：一次撤销同时恢复源图表和目标布局。

第五段：测试完恢复初始位置，再保存重开。

以下图表属于列表内容，应正常显示且没有独立拖动把手。选中完整列表包成布局时，应保持列表和图表的归属，不拆出图表项。

  ```mermaid
  flowchart LR
      L[列表内容] --> R[保留在列表中]
  ```
