# Mermaid 直接拖入

在实时预览中，用下面独立图表右上角的把手拖到图片布局旁边。完整图表进入布局后，源位置不应留副本；一次撤销恢复两处。

<!-- vml {"v":2,"width":0.45} -->
![[attachments/square.png]]
<!-- /vml -->

```mermaid
flowchart LR
%% 保留注释、空行与完整围栏

    A[独立图表] --> B[直接拖入]
```

再拖一次，放到布局外，应取消且源码不变。从图表正文上下滑动应滚动页面；右上角源码按钮仍能编辑。

以下正文用于测试滑动。图表只出现一份，块外文字保持不变。

第一段：Android 手机和平板、iPhone 和 iPad 共用图表实现。

第二段：图表的缩进、注释和空行保持原样。

第三段：拖放只搬运整个围栏，不改写图表节点代码。

第四段：一次撤销同时恢复源图表和目标布局。

第五段：测试完恢复初始位置，再保存重开。
