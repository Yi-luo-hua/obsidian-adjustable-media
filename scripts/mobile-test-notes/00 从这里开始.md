# 移动端专用测试

这是生成器创建的独立测试库。只在此库开启第三方插件和 Adjustable Media。Mobile acceptance 为可选诊断工具，默认关闭。

如果已完成既有移动验收，这轮只打开 **13 Mermaid 混排与触摸** 和 **14 Mermaid 直接拖入**，一次完成其中清单并统一反馈，不必重复下方完整清单。

1. 09：先以实时预览打开，划掉应用后重开，观察普通视频和布局视频的首帧与播放；再切阅读模式。布局视频应页内播放，暂停、进度、主动全屏和返回正常。
2. 01／05：横屏、竖屏全屏查看图片、公式、手动与自动分栏、12 列表格。表格在自己的区域横滑，页面上下滚，侧栏与阅读／实时预览切换正常。
3. 06：两栏点击定位；第一栏输入“移动中文测试”，检查拼音组字、选字、完成、撤销／重做、保存重开，另一栏、+++ 和块外原文保留，最后恢复原文。03 测未闭合的三个反引号：红框草稿不写回、完成后保留、放弃恢复。
4. 08／12：正文两种焦点状态下视频缩放并一步撤销；窄布局两侧空白轻点保持光标／栏内焦点，上下滑动正常，文字和媒体控件仍可操作。
5. 把 Obsidian 窗口缩窄再回全屏，使用设备支持的系统多任务方式。重看 05／06／08；同一笔记打开两个 Obsidian 窗格，一边阅读一边实时预览，确认布局、光标和输入不串窗格。
6. 02：长文快速滚动到中段和末尾，旋转、回桌面再返回，检查内容和滚动位置。

统一反馈操作结果即可；只在问题复现时开启 Mobile acceptance，记录或导出诊断报告。未测试的其他系统中断和主题不记为通过。
