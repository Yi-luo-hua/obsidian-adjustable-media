# Adjustable Media

在笔记里把图片和视频并排摆放，再用拖拽调整顺序和大小。一行最多四个，同一行高度一致。

笔记里保存的仍然是普通的图片嵌入，布局设置写在一条 HTML 注释里。不装插件、在 GitHub 上查看、发布到博客时，图片都照常显示。

[English](README.md)

## 布局块长什么样

```markdown
<!-- vml {"v":2,"rows":[{"height":240,"widths":[1,1.4]}]} -->
![[beach.png]] ![草图](attachments/sketch.png)
![[clip.mp4]]
<!-- /vml -->
```

- 两条注释之间，每一行是一行布局，行里是图片或视频嵌入（`![[…]]` 或 `![…](…)`）。
- 行高、列宽比例、单图的宽度和对齐、图注都写在开始注释里；没有任何设置时，开始注释就是 `<!-- vml -->`。
- 插件从不改写嵌入本身，只改注释里的设置，或者把嵌入整段搬到别处。重命名文件时，Obsidian 会照常更新链接。

## 功能

- 阅读视图和实时预览都按布局显示；在实时预览里，光标移进布局块时显示源码。
- 拖拽图片调整顺序；拖到两行之间会新起一行；也可以拖进同一篇笔记里的另一个布局块。
- 拖动行的底边调整行高，拖动两张图之间的缝隙调整列宽，拖动单张图片的右下角调整宽度。
- 右键菜单：编辑图注、在文件夹中显示、单图行的对齐、移出布局。
- 视频用左上角的把手拖动，不影响进度条和音量。
- 命令：
  - 把选中的图片、视频包成布局块
  - 与下一个布局块合并
  - 移除当前布局块的注释
  - 移除所有笔记中的布局注释（先预览，确认后才执行）
- 自动转换（可选，默认关闭）：拖入或粘贴图片、视频时，新插入的几行自动包成布局块；紧跟在已有布局块后面时并入那个块。
- 界面文字随 Obsidian 的语言显示中文或英文。

## 安装

目前只支持桌面端，测试过的 Obsidian 版本是 1.13.7。

在进入官方插件库之前：

1. 从本仓库最新的 [Release](../../releases) 下载 `main.js`、`manifest.json`、`styles.css`。
2. 放进 `你的库/.obsidian/plugins/adjustable-media/`。
3. 重启 Obsidian，在「设置 → 第三方插件」里启用 Adjustable Media。

## 卸载

直接停用或删除插件即可。笔记里剩下的是普通嵌入和注释（阅读视图里看不到），图片照常显示。想连注释一起去掉，卸载前运行「移除所有笔记中的布局注释」。

## 需要知道的

- 布局设置读不懂时（例如手工改 JSON 出了错），这个块按默认值显示并给出提示，插件不会改写它，修好设置后恢复正常。
- 不装插件时，实时预览里的注释会显示成一行灰字；阅读视图、GitHub 和大多数发布工具都看不到。
- 自动转换只处理拖入或粘贴时新插入的行，打字不会触发它。

## 隐私

插件完全在本地运行，不联网，不收集任何信息。笔记里引用网络图片时，是 Obsidian 自己去加载这些图片。
