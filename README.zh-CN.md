# Adjustable Media

[功能示例](docs/examples/Guide.zh-CN.md) · [Feature examples](docs/examples/Guide.en.md)。在 Obsidian 命令面板打开「功能示例」，可离线预览或创建带素材的示例笔记。首次安装，以及现有用户升级到包含示例的版本时，会自动展示一次。

在 Obsidian 中像排版软件一样，自由拖拽、并排、缩放及用「布局块」格式排版图片/视频内容——基于轻量 HTML 注释存储，保持 100% 原生 Markdown，零格式绑架。

## 核心特性

### 🎨 自由直观的鼠标排版

- **并排与网格**：图片与视频自由并排摆放（每行最多 4 个），同一行自动对齐高度。
- **直接拖拽调尺寸**：拖动两张图之间的缝隙分配宽度（双击缝隙恢复按图片比例分配），拖动行底边调整高度，拖动外框整体缩放。
- **单图自由摆放**：单张图片可在行内左右拖动，靠近左侧、居中、右侧时自动平滑吸附。
- **文字环绕（像 LaTeX 的 `wrapfigure`）**：布局块可以浮到左侧或右侧，笔记自己的段落、列表、引用、标题和代码从旁边绕过，超出图片高度后恢复整行宽度。旁边的文字就是普通正文，直接在图片旁边输入，边打边重排。
- **图片旁的文字栏（像并排的 minipage）**：在布局块里、图片之前写的文字排在图片左边一栏，图片之后写的排在右边一栏，也可以两边都有。文字是普通 Markdown（标题、列表、引用、链接都可以），图片保持布局块的宽度夹在中间，文字可以与图片顶端对齐、垂直居中或底端对齐。实时预览里点一下文字就能在布局里直接修改，编辑时标题、加粗、列表圆点、任务方框、链接、公式和图片都和实时预览里一样，折行的列表项也对齐到文字；按键也和笔记里一样：<kbd>Tab</kbd> 缩进，回车接着写列表，括号自动配对，输入 `[[` 弹出链接建议，Obsidian 的格式、链接、列表、任务和标题命令按你给它们设的快捷键生效（默认是 <kbd>Ctrl</kbd>+<kbd>B</kbd>、<kbd>Ctrl</kbd>+<kbd>I</kbd>、<kbd>Ctrl</kbd>+<kbd>K</kbd>、<kbd>Ctrl</kbd>+<kbd>L</kbd> 这些）；右键图片选 **在左侧添加文字** 或 **在右侧添加文字** 开始写。
- **分栏排版与论文草稿**：文字块可以分成 2–4 栏，文字自动流动、两栏高度自动平衡（相当于 `multicols`），还能设置栏间距、文字对齐（含两端对齐）、字号，窄的块可以居中（右键文字块选 **文字设置…**）。代码、公式和图都可以直接写在文字块里，一整节论文可以就是一个块。
- **图表公式编号与交叉引用**：图注、表注段落末尾写 `{#fig:名字}`、`{#tbl:名字}`，公式里写 `\label{eq:名字}`，正文里写 `@fig:名字`、`@tbl:名字`、`@eq:名字`。图注段首自动加上“图 1”，公式自动编号，引用显示为“图 1”，点击跳到目标。语法与 pandoc-crossref 相同，草稿可以直接转成 LaTeX。编号用中文还是英文可在设置里选。
- **文字块**：布局块里可以只有文字、没有图片。它按布局块的宽度画成一栏 Markdown，也能像图片一样浮到左侧或右侧，让正文从旁边绕过，适合做旁注、边栏。选中几行文字执行包成布局块的命令即可生成；点文字直接修改，拖外框边缘改宽度，右键选择环绕方式，或者取消文字块、保留文字。
- **整块拖动**：拖动外框顶部的手柄即可移动整个布局块。放到正文中间，块落在两段之间；放到左侧或右侧三分之一处，块浮到那一侧，从指针所在的那一行开始环绕。
- **随心拖拽重排**：拖动图片换位、拖到两行之间新建一行，也可以把笔记里的其他图片直接拖进布局块。
- **双击查看大图**：编辑模式下双击布局块中的图片可放大查看，支持鼠标滚轮缩放，可拖拽图片，键盘左右键可在布局块的图片间切换。
- **视频播放**：视频左上角配有专属拖动按键，拖拽排版时不会误触播放与进度条。

### 🛡️ 零格式绑架，数据永久安全

- **原生语法**：笔记中存储的完全是 Obsidian 原生媒体嵌入（`![[...]]` 或 `![...](...)`）。
- **极简注释存储**：布局块参数以最小体积记录在首尾的一对 HTML 注释中（`<!-- vml ... -->` ... `<!-- /vml -->`）。
- **多端与发布无缝兼容**：即使停用插件、在移动端查看，或推送到 GitHub、发布至 Hexo / Quartz / 个人博客，内容依然原样渲染，绝无残损标记或乱码。
- **重命名不失效**：图片、视频文件重命名或移动时，Obsidian 会正常自动更新内部链接，排版完全不受影响。

### ⚡ 融入直觉的编辑流程

- **所见即所得，无缝切换**：编辑模式下具有荧光效果控制框；光标移入或点击「编辑源码」即可切换为纯 Markdown 文本，手写与可视编辑切换便捷。
- **布局边框高亮**：设置中的「保持布局块边框高亮」默认开启；关闭后，鼠标悬停布局或编辑块内文字时显示完整外框，离开后隐藏。
- **自动排版（可选）**：在设置中开启后，从电脑拖入或粘贴的多张图片/视频会自动打包成布局块。
- **原文校验后回写**：活动编辑器内的布局手势使用单次事务，支持原生 Undo/Redo；Markdown 文件没有活动编辑器时通过 `vault.process` 修改，批量清理逐篇校验并写入。每次写入均核对预期原文，保留无关文字与换行符。

## 快速上手

### 1. 创建布局块

- **右键菜单**：在实时预览中右键点击独立的图片、视频或 Mermaid 图表，选择 **包成布局块**。图表按完整的顶层 Mermaid 围栏包装。
- **命令 / 快捷键**：选中单行或多行，执行命令 `Adjustable Media: 把选中的内容包成布局块`（可在快捷键设置中为其指定专属快捷键）。只有媒体嵌入的行合并成图片行；含文字的行原样包进去，成为文字块，或者图片旁的文字栏。
- **选区右键**：在实时预览或源码模式中选中文字，右键选择 **把选中的内容包成布局块**；只有选区能够组成有效布局时才提供此项。
- **拖拽加入**：笔记中已存在布局块时，可将同一笔记、同一窗格中的独立图片或 Mermaid 图表直接拖入其中。触摸设备可拖动图表把手，也可长按独立图表正文后拖动；快速滑动保留滚动。
- **Canvas 卡片**：文字卡片和 Markdown 文件卡片支持各自内部的布局。在卡片的实时预览中包装内容或调整布局，各卡片独立编辑与预览；当前不支持跨卡片拖放布局及 Canvas 内交叉引用导航。
- **Callout 图片**：拖动原生 Callout 中独立图片行的右下角手柄，保存图片宽度，嵌入文本原样保留；这不会把整个 Callout 转成布局块。

## 底层存储原理

Adjustable Media 不创造新语法，笔记中仅保留标准嵌入与纯净的 HTML 注释：

```markdown
<!-- vml {"v":2,"rows":[{"height":240,"widths":[1,1.4]}]} -->
![[beach.png]] ![设计草图](attachments/sketch.png)
![[clip.mp4]]
<!-- /vml -->
```

- 开始注释仅存储必要参数（行高、宽度权重、图注与对齐等），无多余冗余数据。
- 环绕文字的布局块紧贴在被环绕的正文上方，并记下浮到哪一侧：

  ```markdown
  <!-- vml {"v":2,"width":0.4,"wrap":"left"} -->
  ![[portrait.png]]
  <!-- /vml -->
  这一段文字会绕着图片排版，超出图片高度后恢复整行宽度。
  ```

  没有插件时，图片就显示在这一段文字上方。
- 布局块里写在图片之前的文字显示在图片左边一栏，写在图片之后的显示在右边一栏：

  ```markdown
  <!-- vml {"v":2,"width":0.4} -->
  左边一栏：可以写多行、多段，也可以有列表和引用。
  ![[beach.png]]
  右边一栏。
  <!-- /vml -->
  ```

  没有插件时，文字和图片按书写顺序上下排列。
- 嵌入语法原样保留，重命名或文件移动完全兼容。
- 需要清理 Markdown 文件中可编辑的顶层布局注释时，执行命令 `移除所有笔记中的布局块注释…` 并核对确认列表。此命令不扫描 Canvas 文字卡片，也不移除 Callout 图片设置；读不懂的布局会保留。需要清理这些注释时，可手动只删注释、保留原内容。

## 安装与环境要求

- **环境要求**：Obsidian 1.5.0 及以上版本，支持桌面、Android、iPhone 和 iPad。各设备与构建的验证范围见[项目状态](docs/STATUS.md)和[移动记录](docs/plans/layout-redesign/mobile-adaptation.md)；近期桌面修复并未全部在移动端复测。

### 方式一：社区插件市场（推荐）

1. 打开 Obsidian「设置 → 第三方插件」，关闭安全模式。
2. 点击「浏览」，搜索 **Adjustable Media**。
3. 点击「安装」，完成后点击「启用」。

### 方式二：手动安装

1. 前往 [Releases 页面](https://github.com/Yi-luo-hua/obsidian-adjustable-media/releases/latest) 下载最新的 `main.js`、`manifest.json`、`styles.css`。
2. 将文件放入库目录下的 `.obsidian/plugins/adjustable-media/` 文件夹中。
3. 重启 Obsidian 并在第三方插件列表中启用。

## 注意事项

- 完整布局块需位于正文顶格起始位置，不支持放置在引用块（Quote）、标注框（Callout）或列表中。Callout 内独立图片行的缩放使用单独的设置注释，不属于完整布局块。
- 阅读视图只显示布局块；调整布局块请在实时预览里进行。
- 媒体布局里的文字应写在第一行媒体之前（左栏）或最后一行媒体之后（右栏），夹在两行媒体之间会使该布局无效。只有文字的块，或声明 `type:"text"` 的块，全部内容按文字处理，媒体可以嵌在文字任意位置。有文字栏的媒体布局不做正文环绕。
- 不收集遥测或分析数据。本地媒体可离线使用；笔记中嵌入的远程媒体仍会从原始网址加载。

## 0.7.3：手动文字分栏（已发布）

在文字布局块内把 `+++` 顶格独占一行，即可结束当前栏并开始下一栏。最多四栏，等宽、顶部对齐，每栏保留自己的内容，也可以留出空栏。没有标记时保留自动分栏。点击文字进入编辑后可直接输入标记，编辑源码时可用「插入分栏标记」命令。代码、公式和注释中的标记不参与分栏；超过四栏会提示并回退为自动分栏，原文保持不变。

本版同时修复文字编辑器之间切换、点击外框空隙时误展开源码的问题。更新说明中的按钮可按界面语言离线创建[中文样例](docs/examples/ManualColumns.zh-CN.md)或[英文样例](docs/examples/ManualColumns.en.md)，每次使用新目录，不覆盖已有笔记。

用户最终确认、中英文 Windows／Obsidian 1.14.4 定向实测、327 项自动检查和发布构建均已完成。0.7.3 已从 `codex/text-column-breaks` 推送标签，基于正式 0.7.2 并保留其功能；GitHub 正式发布及三份带来源签名的附件已核对，发布索引已合并，该阶段的公开版本为 0.7.3。验证范围见[项目状态](docs/STATUS.md)和[实施记录](docs/plans/layout-redesign/34-text-column-breaks.md)。0.7.3 当时保持桌面限定与 V2 格式；当前版本与移动支持范围见页首。
