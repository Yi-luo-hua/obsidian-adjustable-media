# Adjustable Media

在 Obsidian 笔记里把图片和视频并排摆放，用鼠标拖动来调整位置和大小。

笔记里存的仍然是普通的图片嵌入，布局只占一条 HTML 注释。不装插件、在 GitHub 上查看、发布到博客，图片都照常显示。

[English](README.md)

## 功能

- **一行最多四个**：图片和视频并排，同一行高度一致；阅读视图和实时预览都能用。
- **拖动排版**：调整顺序、拖到两行之间新起一行，或者拖进同一篇笔记里的另一个布局。
- **用鼠标调大小**：行高、两张图之间的宽度分配、单张图的宽度，都可以直接拖。
- **图注和对齐**：在右键菜单里设置。
- **视频照常播放**：视频用左上角的小把手拖动，进度条和音量不受影响。
- **自动排版**（可选）：从电脑或 Obsidian 文件列表拖入、或者粘贴的图片、视频，自动排进布局。
- **不锁定格式**：卸载插件后，笔记里的图片仍是普通嵌入，照常显示。

## 使用方法

### 创建布局

选中几行图片或视频嵌入（或者把光标放在其中一行），打开命令面板，运行 **Adjustable Media: 把选中的图片、视频包成布局块**。这些嵌入会按顺序排好，每行最多四个。

也可以在插件设置里打开 **自动转换拖入或粘贴的图片、视频**。之后从电脑或 Obsidian 文件列表拖入、或者粘贴到笔记里的图片、视频会自动包成布局；紧跟在已有布局下面时，会并入那个布局。

### 调整位置和大小

| 想要 | 操作 |
| --- | --- |
| 移动图片 | 直接拖：放到另一张图旁边、两行之间（新起一行），或者同一篇笔记里的另一个布局上 |
| 移动视频 | 拖视频左上角的把手 |
| 调整行高 | 拖这一行的下边缘 |
| 调整两张图的宽度分配 | 拖两张图之间的缝隙 |
| 调整单张图的宽度 | 拖它的右下角 |
| 图注、对齐、移出布局、在文件列表中显示 | 右键点击，或者选中后按 <kbd>Shift</kbd>+<kbd>F10</kbd>。菜单里还有 Obsidian 自带的文件操作，比如在文件列表或系统资源管理器中显示 |
| 编辑源码 | 在实时预览里点布局角上的 **编辑源码**，或者把光标移进布局 |

拖动时按 <kbd>Esc</kbd> 可以取消。

### 命令

- **把选中的图片、视频包成布局块**
- **与下一个布局块合并**：合并中间只隔着空行的两个布局。
- **移除当前布局块的注释**：把光标所在的布局还原成普通嵌入。
- **移除所有笔记中的布局注释…**：先列出会改动的笔记，确认之后才执行。

## 笔记里存的是什么

```markdown
<!-- vml {"v":2,"rows":[{"height":240,"widths":[1,1.4]}]} -->
![[beach.png]] ![草图](attachments/sketch.png)
![[clip.mp4]]
<!-- /vml -->
```

两条注释之间的每一行是一行布局。行高、宽度、对齐和图注写在开始注释里；没有任何设置时，开始注释就是 `<!-- vml -->`。插件从不改写嵌入本身，所以重命名或移动文件时，Obsidian 会照常更新链接。

## 安装

**从第三方插件市场安装**

1. 打开「设置 → 第三方插件」，如果开着安全模式，先关掉。
2. 点 **浏览**，搜索 **Adjustable Media**，点 **安装**，再点 **启用**。

也可以打开[插件页面](https://obsidian.md/plugins?id=adjustable-media)，点 **Add to Obsidian**。

**手动安装**

1. 从[最新的 Release](https://github.com/Yi-luo-hua/obsidian-adjustable-media/releases/latest) 下载 `main.js`、`manifest.json`、`styles.css`。
2. 放进 `你的库/.obsidian/plugins/adjustable-media/`。
3. 重启 Obsidian，在「设置 → 第三方插件」里启用 **Adjustable Media**。

目前只支持桌面端。需要 Obsidian 1.5.0 或更新版本，在 1.13.7 上测试过。

## 需要知道的

- 布局必须从行首开始，所以不能放在标注块（callout）、引用或列表里。
- 布局里的每一行只能有图片或视频嵌入。混进其他内容的布局不会被接管，按普通 Markdown 显示。
- 布局设置读不懂时（比如手工改坏了），会按默认值显示并给出提示；在设置修好之前，插件不会改动这个布局。
- 不装插件时，实时预览里的注释会显示成一行灰字；阅读视图、GitHub 和大多数发布工具都看不到。
- 想干净地卸载，可以先运行 **移除所有笔记中的布局注释…**。不运行也没关系，图片照样显示。

更多问题见 [FAQ](docs/FAQ.md)（英文）。

## 隐私

插件完全在本地运行，不联网，不收集任何信息。笔记里的网络图片由 Obsidian 自己加载。

插件只读取它正在显示或修改的笔记。唯一的例外是 **移除所有笔记中的布局注释…**：只有在你运行这条命令时，它才会读取库里的全部笔记，用来找出要移除的布局。

## 开发

```bash
npm ci
npm run dev
```

`npm run dev` 会在每次改动后重新生成 `main.js`。提交 PR 之前请运行 `npm run check`，它会做类型检查、用官方插件审核的规则（[eslint-plugin-obsidianmd](https://github.com/obsidianmd/eslint-plugin)）做 lint，并运行测试。格式和架构见 [docs/DESIGN.md](docs/DESIGN.md)，开发约定见 [AGENTS.md](AGENTS.md)。
