# Adjustable Media

Obsidian 图文布局插件：在实时预览中拖拽调整图片、视频、Mermaid、本地 Excalidraw 和网页嵌入的大小与排版，配置保存在 `<!-- vml ... -->` HTML 注释中，不改写原始 Markdown 语法。

[English](README.md) · [简体中文](README.zh-CN.md)

最新版本：**[1.2.0](https://github.com/Yi-luo-hua/obsidian-adjustable-media/releases/latest)** · [更新日志](CHANGELOG.md) · [功能示例](docs/examples/Guide.zh-CN.md) · [Agent 指南](docs/examples/AgentGuide.zh-CN.md) · [常见问题](docs/FAQ.md) · [文档索引](docs/README.md)

在 Obsidian 命令面板运行「功能示例」，可离线预览或创建带素材的示例笔记。

## 功能说明

- **多类媒体并排与网格**：支持图片、视频、Mermaid 图表、本地 Excalidraw 绘图（需启用 Excalidraw 插件）、PDF++ 矩形选区（需启用 PDF++ 插件）和网页嵌入（`<iframe>`、YouTube、Twitter/X）。每行最多 4 项，自动对齐行高。
- **直接拖拽调尺寸**：拖两项之间的缝隙改列宽（双击按原比例还原），拖行底边改行高，拖网页组件底边设独立高度，拖外框边缘或底角缩放整块。
- **定位与文字环绕**：单图（或单组件行）可在行内左右拖动并吸附到左/中/右或任意位置；较窄的未环绕块可横向拖动顶部把手摆放在同一行任意水平位置（阅读模式和 PDF 导出保持同样相对位置）。媒体块和纯文字块都能设为左/右浮动，让正文、列表、引用、标题和代码环绕排版；正文顶层分隔线 `---` 自动结束环绕。
- **图片旁文字栏**：在媒体前写左栏、媒体后写右栏，支持顶端、居中、底端对齐。实时预览里点击文字即可直接按实时预览样式修改，支持列表悬挂缩进、<kbd>Tab</kbd>/回车、`[[` 链接建议以及 Obsidian 格式快捷键。外框侧边/底角可独立于图片栏比例调整整体宽度。
- **文字块与多栏排版**：纯文字块可作为普通边栏或浮动旁注；右键「文字设置…」可开启 2–4 栏自动平衡分栏，自定义栏间距、文字对齐（含两端对齐）与字号。在正文顶格写单独一行的 `+++`（或运行「插入分栏标记」）可手动分出最多 4 栏等宽栏目。
- **图注与学术交叉引用**：支持单项图注和整组布局下方的「整组图注」（均支持 Markdown、编号、居左/居中及默认/125%/150%/200% 字号）。图注/表注末尾写 `{#fig:名字}` 或 `{#tbl:名字}`，公式内写 `\label{eq:名字}`，正文用 `@fig:名字`、`@tbl:名字`、`@eq:名字` 自动按中英文编号并点击跳转到目标（兼容 pandoc-crossref 语法）。
- **拖拽重排与看图弹窗**：同笔记同窗格中的独立媒体可直接拖入已有布局块，块内支持同行换位或拖到两行之间拆行。实时预览双击图片可看大图（滚轮缩放、拖拽、方向键切换）；双击 Excalidraw 预览打开原图。视频、Mermaid、Excalidraw 和网页嵌入配有专属拖动手柄，不会误触播放或内部控件。
- **Canvas、Callout 与表格**：Canvas 文字卡片和 Markdown 文件卡片内部各自独立支持布局；原生 Callout 中的独立图片行可通过右下角手柄缩放（`scope:"callout-image"`）；实时预览右键顶层 Markdown 表格（Obsidian 1.6.0+）可包成文字布局块，同时保留原生行、列与排序菜单。
- **不破坏原笔记**：原嵌入链接、Mermaid 围栏和 `<iframe>` 源码原样保留，文件重命名自动更新链接；停用插件或导出发布时只保留普通 Markdown 和 HTML 注释。

## 使用方法

### 创建布局块

- **右键菜单**：在实时预览中右键独立图片、视频、Mermaid 图表、Excalidraw 预览、PDF++ 矩形选区、网页嵌入把手或顶层 Markdown 表格，选择 **包成布局块**。Obsidian 1.6.0 或更新版本也支持右键包装 Markdown 外链图片，包括网址没有文件后缀的图片。普通正文行里文字与图片混排时，只拆出点击的那张图片。
- **选区 / 命令**：选中几行内容后右键，或运行命令 **把选中的内容包成布局块**（默认不设快捷键，可在**设置 → 快捷键**绑定）。
- **拖入已有布局**：把同笔记同窗格的独立图片、Mermaid、Excalidraw 把手或网页嵌入把手直接拖进已有布局块。触摸设备上长按独立 Mermaid 正文可拖动。
- **自动转换（可选）**：在设置中开启「自动转换拖入或粘贴的图片、视频」，新拖入或粘贴的媒体会自动包成布局块。

### 常用交互

| 操作 | 方式 |
| :--- | :--- |
| 调整列宽比例 | 拖动两项之间的缝隙；双击恢复按原比例分配 |
| 调整行高 / 网页独立高度 | 拖动行底边，或拖动网页组件底边（双击网页把手或用菜单重置） |
| 缩放整块布局 | 拖动外框边缘或底角（图文块的外框调整体尺寸，图片栏调栏宽与媒体尺寸） |
| 调整单图/单组件行位置 | 在行内左右拖动 |
| 横向摆放窄布局块 | 横向拖动较窄且未开启环绕的块顶部把手 |
| 移动整块位置 / 触发环绕 | 上下拖动顶部把手移动到其他段落（放到正文左右三分之一处开启环绕） |
| 换位与跨行移动 | 拖动组件到同行其他位置、两行之间新建行或另一布局块（视频/Mermaid/Excalidraw/网页用各自专属把手） |
| 环绕、文字栏与图注 | 右键组件或外框，设置左/右环绕、左/右文字栏、对齐方式、单项/整组图注或**移出布局块** |
| 编辑源码 / 取消 / 撤销 | 将光标移入块内或点击右上角「编辑源码」；拖动中按 <kbd>Esc</kbd> 取消；每次操作支持一步撤销 |

### 设置与命令

- **设置项**：界面语言、图表编号的语言（跟随 Obsidian / 中文 / 英文）、自动转换拖入或粘贴的图片、视频（默认关）、保持布局块边框高亮（默认关）、阅读模式显示布局块边框（默认关）、布局块边框颜色（默认跟随主题强调色）、功能介绍。
- **命令**：`把选中的内容包成布局块`、`与下一个布局块合并`、`插入分栏标记`、`移除当前布局块的注释`、`移除所有笔记中的布局块注释…`、`功能示例`、`查看更新说明`。

## 存储格式

布局只在外层包裹一对 HTML 注释，内部嵌入保持原样：

```markdown
<!-- vml {"v":2,"rows":[{"height":240,"widths":[1,1.4]}]} -->
![[beach.png]] ![设计草图](attachments/sketch.png)
![[clip.mp4]]
<!-- /vml -->
```

**文字环绕**紧贴在被环绕段落上方（`wrap: "left" | "right"`，可选 `skip` 错开行数）：

```markdown
<!-- vml {"v":2,"width":0.4,"wrap":"left"} -->
![[portrait.png]]
<!-- /vml -->
这一段文字会绕着图片排版，超出图片高度后恢复整行宽度。
```

**图片旁文字栏**：媒体前为左栏，媒体后为右栏：

```markdown
<!-- vml {"v":2,"width":0.4} -->
左边一栏：段落、列表、引用、公式都可以。
![[beach.png]]
右边一栏。
<!-- /vml -->
```

**Mermaid 与网页嵌入（`v:3`）**原样保留完整围栏与 `<iframe>`，并可记录各项独立 `heights`；**Callout 单图**使用带 `>` 前缀的 `<!-- vml {"v":2,"scope":"callout-image","rows":[{"width":0.5}]} -->`。

运行 **移除所有笔记中的布局块注释…** 可预览并批量清理 Markdown 文件中的可编辑顶层布局注释（不处理 Canvas 卡片、Callout 图片设置与无法解析的块）。

## 安装

需要 Obsidian **1.5.0+**（表格右键菜单需 **1.6.0+**），支持桌面端与 Android / iPhone / iPad（`isDesktopOnly: false`；具体设备验证范围见[项目状态](docs/STATUS.md)与[移动记录](docs/plans/layout-redesign/mobile-adaptation.md)）。

1. **社区插件市场**：打开 Obsidian「设置 → 第三方插件」，关闭安全模式，搜索 **Adjustable Media** 安装并启用。
2. **手动安装**：从 [Releases 页面](https://github.com/Yi-luo-hua/obsidian-adjustable-media/releases/latest)下载 `main.js`、`manifest.json` 和 `styles.css`，放入 `<库目录>/.obsidian/plugins/adjustable-media/` 后启用。

## 注意事项

- 完整布局块必须从正文顶格行开始，不能放在引用、Callout 或列表内部。
- 阅读视图只展示排版，修改需在实时预览中进行。
- 媒体布局中文字不能夹在两行媒体之间，否则该块不接管；若需图文混插，请在开始注释中加上 `"type":"text"`。带左右文字栏的媒体布局不做正文环绕。
- 无遥测或数据收集；远程图片和网页嵌入直接从原网址加载。
