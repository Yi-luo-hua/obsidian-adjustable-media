# Excalidraw 布局媒体

2026-11-02，处理 [Issue #36](https://github.com/Yi-luo-hua/obsidian-adjustable-media/issues/36)。实现已进入 main，尚未发布；公开版 0.9.2 不包含此功能。

## 使用

启用 Excalidraw 插件后，本地 `.excalidraw`、`.excalidraw.md` 绘图可作为布局媒体，与图片、视频、Mermaid 混排，使用现有调宽、环绕和图注操作。

```markdown
<!-- vml {"width":0.3,"wrap":"right","rows":[{"captions":["流程草图"]}]} -->
![[diagram.excalidraw|240]]
<!-- /vml -->
这里是环绕绘图的普通正文。
```

图文并排可直接在块内图片行之前／之后写文字。已有 `type:"text"` 块仍是文字块，其中的 Excalidraw 也能显示；不自动改成媒体布局。

- 原生 Excalidraw 预览右键提供「包成布局块」；已有布局时显示专用拖动把手，可拖入同笔记同窗格的布局。
- 布局内用专用把手移动绘图，双击预览打开原图。
- 嵌入原文、别名、已有尺寸及局部引用原样保存；Markdown 链接也支持。
- 普通 `.md` 笔记与远程 Excalidraw URL 不作为绘图接管。绘图里的链接不在图片预览中直接点击，需打开原图操作。
- 未启用 Excalidraw 时显示提示。启用后重开笔记或重载 Adjustable Media。

## 接入方式

原生 Excalidraw 2.29.0 的 Markdown 后处理器跳过未连接文档的嵌入。测试库中，即使先挂入外层容器，MarkdownRenderer 仍会暂存内层段落，不能依靠这条路径稳定显示布局绘图。

因此通过可选插件实例取得 ExcalidrawAutomate 类，每次导出使用自己的实例调用 `createSVG`，包含字体并交给原插件处理局部引用，最后销毁实例。使用内存 Blob URL，替换／卸载时释放；不生成 SVG 副本，不清空共享 Automate 状态。此类入口通过社区插件实例访问，不属于 Obsidian 官方 App 类型；已核对 Excalidraw 2.29.0，后续插件 API 变化需相应维护。

监听绘图文件保存和明暗主题变化。刷新不会写笔记；关闭后不安装异步结果。文字块只在渲染副本中替换真实嵌入，行内代码、围栏代码、公式、frontmatter 和注释保留。

## 本轮验证

- Node 24.11.1：`npm run check`（527 项测试，lint 0 错误）、生产构建通过。覆盖解析与局部引用、原文守恒、过期写入拒绝、异步竞态、URL 与监听清理、缺失插件／导出失败回退。
- Windows 11／Obsidian API 1.14.5（Electron 应用 UA 显示 1.14.4）／默认主题／Excalidraw 2.29.0：实时预览与阅读模式的多图、图文、右浮动、显式文字块正常显示；截图确认并排及正文环绕。
- 真实鼠标输入：Esc 取消列宽调整零写入，调整后一步撤销，嵌入文本保留；原生 SVG 和 SVGIMG 两种预览可通过把手拖入，媒体数量不变、一步撤销恢复。右键菜单取消零写入，双击打开原图。
- 修改绘图后预览宽度由 320 更新为 440，恢复后回到 320。静置 1 秒没有重复 SVG 导出，连续 20 次高度采样一致；滚动往返与模式切换后恢复显示。
- wiki 与 Markdown 的局部引用分别显示整矩形（320×170）和单文字元素（176×45），没有把局部引用丢成整图。
- 直接调用本插件的 PDF 渲染入口：4 个布局、4 张绘图、2 个浮动，图片全部加载。没有执行完整的桌面 PDF 导出对话框与分页验收。
- 停用 Excalidraw 并重载 Adjustable Media 后显示启用提示；重新启用后恢复。会修改的测试笔记与绘图均备份、恢复，并核对 SHA-256。
