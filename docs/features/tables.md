# 表格布局项

2026-11-02，实现已进入 main，尚未发布；公开版 0.9.2 不包含此增量。

## 使用

实时预览中右键普通 Markdown 表格，选择「包成布局块」。无论光标在哪里，都会包装右键点击的完整表格，并保留原生的行、列和排序菜单。菜单关闭不写入，包装可一步撤销。

右键包装保留普通表格的宽度、水平位置与上下留白，窄表不会自动撑满正文；超宽表格统一等比缩进正文／布局可用宽度，不提供横向滚动。独立图片、Mermaid 和 Excalidraw 的右键包装同样记录显示尺寸与位置，设置只写进注释。源码选区包装仍沿用原有布局规则。

表格可与图片、视频、Mermaid、Excalidraw 或其他表格并排，也支持左右文字栏、左／右浮动、调宽、图注与编号。拖动专用把手移动完整表格；已有布局时，块外原生表格也会显示可拖入的把手。双击布局中的表格展开所在块的源码，编辑后回到预览。

```markdown
<!-- vml {"v":3,"kind":"media","rows":[{"items":2}]} -->
| 项目 | 数量 |
| :--- | ---: |
| 第一组 | 10 |

| 项目 | 数量 |
| :--- | ---: |
| 第二组 | 20 |
<!-- /vml -->
```

`items` 决定同一行里的完整项数，例子中的两张表在源码里仍是两张独立表格。选中完整表格执行现有包装命令也会生成 V3 布局。单表浮动可在开始注释加入 `"width":0.35,"wrap":"right"`，或使用布局菜单。

表格先按完整内容排版；超过所在项的可用宽度时，文字、边框和行高一起等比缩小，完整显示全部列，不裁掉右侧内容，也不横向滚动。表格越宽、布局越窄，显示的文字就越小；放得下的小表格保持原字号，不放大。拖窄／拖宽布局、调整窗格及并排栏宽时自动重新适配。纯表格布局只提供宽度调整；混合行的高度把手继续调整图片／视频等媒体，表格高度随实际缩放结果变化。

## 源码与兼容

- 保留整张表格的表头、分隔行、对齐符、转义、数据行、行内格式和尾随空白。设置写回只改注释；移动时完整搬运表格。
- 只识别顶层 Markdown 管道表格，不把 HTML 表格、列表／引用内表格或代码示例当作独立媒体。遇到不可安全读取的数据行，整表拒绝包装。
- V2 布局及显式 `type:"text"` 块中的表格继续按文字渲染，不自动迁移。旧版插件不识别独立表格项，不能保证降级排版；不认识完整项数时会只读回退。
- 原生右键菜单接入使用 Obsidian 1.6.0 引入的 `Menu.forEvent`；更旧宿主可选中源码后使用现有包装命令。没有更改插件最低安装版本。
- 旧未发布滚动方案留下的 `tableViewport` 设置不再参与显示，原字段仍原样保留；已有布局也直接应用等比缩放，无需重新包装，不自动改写笔记。
