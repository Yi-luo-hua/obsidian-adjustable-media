# 表格右键包装

2026-11-02：已撤回表格独立媒体项、整表缩放、专属宽高把手与拖入并排等适配。实现以表格适配前的 `2bba25b` 检查点为基础，仅保留原生表格右键「包成布局块」入口；Excalidraw 支持保留。已随 0.9.3 正式发布，见[发布核验](../releases/0.9.3-readiness.md)。

在实时预览中右键顶层 Markdown 表格，选择「包成布局块」，会将点击的完整表格包装为原有的文字布局块：

```markdown
<!-- vml {"v":2,"type":"text"} -->
| Name | Value |
| --- | --- |
| Alpha | 10 |
<!-- /vml -->
```

表格继续由普通 Markdown 渲染，沿用文字布局块已有的宽度、环绕与源码编辑行为。表头、分隔行、数据行、转义和尾随空白保持原样，不转成独立媒体项。

右键菜单保留 Obsidian 的行、列和排序动作；入口使用 Obsidian 1.6.0 起的 `Menu.forEvent`。代码、公式、注释、列表／引用及已有布局中的表格不重复包装，无法安全识别的数据行使整表拒绝包装。点击菜单时重新校验笔记原文和目标元素；取消零写入，包装可一步撤销。

验证：Node 24 下类型检查、lint（0 错误）、534 项测试和生产构建通过。Windows／Obsidian API 1.14.5 实测右键第二张重复表格，保留行／列／排序菜单，生成 V2 文字块且只包装点击的表格，表格原文完整保留，一步撤销恢复原样；测试笔记 SHA-256 恢复一致，开发控制台未捕获错误。未复测其他平台和主题。
