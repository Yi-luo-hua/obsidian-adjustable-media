# 0.9.2 发布核验

日期：2026-10-24。正在准备补丁版本；公开版本仍为 0.9.1。

## 范围

- 基于 main `ed83461`，包含布局转换后的预览与光标定位修复，以及同行文字误入图片布局的右键菜单修复。
- 图片嵌入原样保留，前后文字留在块外；原选区碰到转换范围时移到转换内容后的空行。一步撤销还原原文，重做恢复块外光标。
- 同步版本文件、锁文件、中英文包内公告与更新弹窗版本；沿用各语言上一版的支持和反馈结尾。最低 Obsidian 声明版本仍为 1.5.0，不迁移已有布局。

## 验证

- 功能修复阶段：Node 24.11.1，类型检查、lint、519 项测试及生产构建通过。
- 0.9.2 发布候选：`npm run check` 通过（519 项测试），`npm run release` 仅输出 `main.js`、`manifest.json`、`styles.css`，版本与最低版本映射一致。
- Windows／Obsidian 1.14.5／专用测试库：文末转换后直接绘制布局，块外继续输入、一步撤销与重做通过。`S6 拖入与粘贴.md` 副本用真实右键操作验证“输入几个字”留在布局外，图片独立成块；原笔记与恢复后的副本 SHA-256 一致。
- 发布候选加载至同一测试库：从 0.9.1 升级自动显示中文 0.9.2 公告，同版重载不重复弹窗，手动打开英文公告显示对应三条更新；两种语言截图已目视核对。测试插件三份文件及设置已逐字节恢复，52 份既有 Markdown／Canvas 文件哈希不变。
- 移动设备、其他主题与 PDF 本轮未复测。
