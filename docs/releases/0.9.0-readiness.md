## 验证边界

既有 Windows／Obsidian 1.14.4 的定向实测见 [STATUS](../STATUS.md)和[Canvas 记录](../archive/2026-10-19-canvas-support.md)。本次整合后的检查和测试库验证如下；标签、工作流、附件摘要和来源签名见下文正式发布记录。

- Node 24.11.1：`npm run check` 通过类型检查、lint 和全部 500 项测试；`npm run release` 生成标准三文件生产包。
- 0.9.0 集成包，Windows／Obsidian 1.14.4／默认主题／`vml-test-vault`：真实右键包装独立 Mermaid，围栏原文与一步撤销通过；Callout 图片缩放预览、Esc 取消零写入、松手保存和一步撤销通过；库外 file URL 图片在 Callout、普通布局、阅读视图及 Canvas 卡片加载成功。
- Canvas 文字卡片的图片＋Mermaid 布局及 Markdown 文件卡片预览通过，屏幕截图已目视核对；本轮未重复卡片编辑全流程，原专项操作结果仍限于其各自构建。
- 中英文 0.9.0 更新弹窗已打开核对，中文截图已目视检查。临时测试笔记恢复原文并核对哈希后移入系统回收站；98 篇原有笔记哈希一致，测试插件四份文件逐字节恢复，原窗格布局已恢复。


移动设备、本次完整 PDF 回归和全部主题未复测。Canvas 不包含跨卡片布局拖放、文字卡片的全库批量移除、交叉引用导航；文件卡片标题／块子路径及 Canvas 导出未验收。Callout 行内图片、多图同行和既有外层布局中的图片不提供此缩放手柄。Issue #29 尚未复现，不认定修复。

本地构建与核验证据位于忽略目录 `dist/release-0.9.0/`。
