This update adds manual text columns and fixes clicks on layouts unexpectedly revealing their source.

### Choose how much content goes in each column

Write `+++` on its own unindented line inside a text layout to start the next column. Columns have equal widths, align at the top, and can contain different amounts of text. Content wraps within its own column instead of flowing into another one. Up to four columns are supported.

Layouts without markers keep their automatic columns, so existing notes need no changes. Markers in code, math and comments do not start a new column. With the plugin disabled, the markers appear as ordinary text.

More usage examples: [Create manual column examples in vault](https://raw.githubusercontent.com/Yi-luo-hua/obsidian-adjustable-media/0.7.3/docs/examples/ManualColumns.en.md)

### Click and text editing fixes

- Clicking another layout while editing text opens the corresponding text editor instead of revealing the whole layout's source.
- Clicking frame padding, the column overflow warning, or empty space near a handle keeps the current editing focus and selection.
- You can switch directly between a layout's left and right text columns. Text that cannot be saved stays in its original editor, so switching columns does not discard it.
