This update brings three improvements to layout controls.

### Reset column widths with a double-click

Double-click a divider between media to restore the row's widths to the media proportions. Press Ctrl+Z to undo in one step.

### Resize the frame while keeping image size

Dragging the frame's right edge changes its width while keeping single images at their size, until the frame becomes too narrow. Corner dragging still scales images.

### Show layout borders when needed

Keep layout borders highlighted is enabled by default. Turn it off to show the full border and glow on mouse hover or while editing the layout.

Mobile support is still in active development.
