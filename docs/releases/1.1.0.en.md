- **Wrap and arrange remote images.** Right-click a remote image in Live Preview to wrap it in a layout, or drag it into an existing layout and resize it. This also works for image URLs without a recognized file extension. The context menu action requires Obsidian 1.6.0 or later.
- **Restore stretched images and missing controls after an update.** The plugin restores `styles.css` on startup if the file is missing or empty. Existing layouts regain their image proportions and resize handles.
