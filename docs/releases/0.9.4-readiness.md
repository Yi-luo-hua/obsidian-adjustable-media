# 0.9.4 发布准备

日期：2026-11-05。准备 0.9.4，当前公开最新版本仍为 0.9.3。

## 范围

- 基于 main `c2d511d`，包含 [#38 网页嵌入布局](../features/web-embeds.md)、组件菜单开关和拖入／移出操作，以及[文档打开时的编辑器初始化兼容修复](../archive/2026-11-05-editor-initialization.md)。
- 同步版本、锁文件、中英文更新正文和弹窗版本。更新说明使用四条简短文字，不接入网页示例文档或创建示例按钮。
- 最低 Obsidian 版本仍为 1.5.0，保留移动端安装声明，不批量迁移已有笔记。

## 验证边界

- 功能阶段：558 项检查、生产构建及 Windows 定向验证通过。网页拖入、右键移出、再拖回、取消零写入、逐步撤销和菜单点击开关已实测；编辑器初始化修复在 Windows／Obsidian API 1.15.0 验证，尚未取得反馈者环境的恢复确认。
- iframe 内容可用性取决于网站、登录、地区及网络。B 站示例在本机站外播放返回错误，不计为视频播放验收通过。
- macOS、移动真机、其他主题、旧版 Obsidian及完整 PDF 导出／分页本轮未复测。

## 候选与草稿

- Node 24.11.1：`npm run check` 通过（558 项测试，lint 0 错误），`npm run release` 只输出三个标准文件，版本映射一致。
- Windows 专用测试库：从 0.9.3 升级显示中文 0.9.4 公告，同版重载不重复弹出，手动英文说明对应四条更新；中英文截图已目视核对，正文没有示例文档入口。
- 测试插件、manifest 和设置逐字节恢复；72 份 Markdown／Canvas 笔记 SHA-256 不变，控制台未捕获错误。
- 草稿附件和来源证明核验完成后补充；本次仅准备，不公开发布。
