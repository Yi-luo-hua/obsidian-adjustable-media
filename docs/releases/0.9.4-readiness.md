## 验证边界

- 功能阶段：558 项检查、生产构建及 Windows 定向验证通过。网页拖入、右键移出、再拖回、取消零写入、逐步撤销和菜单点击开关已实测；编辑器初始化修复在 Windows／Obsidian API 1.15.0 验证，尚未取得反馈者环境的恢复确认。

- macOS、移动真机、其他主题、旧版 Obsidian及完整 PDF 导出／分页本轮未复测。
