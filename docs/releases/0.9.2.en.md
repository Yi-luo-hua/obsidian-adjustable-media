- Keep new layouts rendered in live preview after wrapping images or selected content. Move an affected selection to a blank line after the converted content so you can continue typing. One undo restores the original text; redo keeps the cursor outside the layout.
- When wrapping an image that shares a normal paragraph line with text, put only the clicked image in the media layout. Keep surrounding text outside and preserve the image link, aliases and dimensions.
- Cancel conversion if the note changes or the original image widget disappears while its context menu is open.
