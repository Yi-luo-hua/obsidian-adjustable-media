- 支持将 Excalidraw 绘图放进布局，与图片、视频和 Mermaid 并排，使用调宽、环绕、图注和拖动把手；双击预览打开原图。需要启用 Excalidraw 插件。
- 绘图保存或明暗主题切换后自动刷新预览；显式文字布局块中的绘图也能正常显示。嵌入链接、别名、尺寸和局部引用原样保留，不生成额外 SVG 文件。
- 实时预览中右键顶层 Markdown 表格，可选择「包成布局块」，将整表包装为文字布局块，沿用文字块的调宽与环绕；保留原生行、列和排序菜单，支持一步撤销。
