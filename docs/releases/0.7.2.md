# 0.7.2 更新说明

发布日期：2026-10-09。本版面向桌面端，集中交付三项独立操作改进；笔记仍使用 V2 格式，无需迁移。

## 双击分隔线恢复列宽

在实时预览中，双击同一行两张媒体之间的列宽分隔线，即可取消手动列宽，让整行重新按媒体宽高比分配。只有分隔线响应这个恢复操作；双击图片仍按原来的方式打开看图。恢复操作支持一步撤销。

## 调整外框宽度时保持单图大小

拖动布局外框右边缘时，外框收紧或放宽，单图保持原来的屏幕尺寸。外框窄到无法容纳图片时，图片才随可用空间缩小。右下角仍用于缩放图片与布局；靠右浮动布局的对应把手位于左侧。

## 可关闭常驻边框高亮

在「设置 → Adjustable Media」中新增「保持布局块边框高亮」，默认开启，保留旧版本的显示习惯。

关闭后，鼠标进入布局块范围（包括框内空白）时显示完整外框与光晕，方便定位和操作；鼠标移出且块内没有编辑焦点时隐藏。编辑布局文字栏时也会保持高亮。开关即时生效并保存，不改变布局尺寸或笔记内容。

## 安装与兼容

已安装用户可在 Obsidian 第三方插件设置中检查更新。也可从 [0.7.2 Release](https://github.com/Yi-luo-hua/obsidian-adjustable-media/releases/tag/0.7.2) 下载 `main.js`、`styles.css` 和 `manifest.json`，放入测试或目标库的 `.obsidian/plugins/adjustable-media/` 后重启 Obsidian；保留自己的 `data.json` 设置文件。

本版仍为桌面端插件，要求 Obsidian 1.5.0 或更新版本；本轮定向操作验证使用 Windows／Obsidian 1.14.4。自动检查通过，操作、撤销、高亮与悬停已在独立测试库验证，并经用户最终确认。
