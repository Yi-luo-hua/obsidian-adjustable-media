This update adds Mermaid layout items and brings recent rendering, text input and interaction fixes to Android, iPhone and iPad.

### Arrange Mermaid diagrams like images

Select a complete Mermaid code block and run **Wrap selection in a layout** to place it beside images, videos or other diagrams. In Live Preview, drag an ordinary diagram into an existing layout and adjust column widths, row height and overall size.

Diagrams use Obsidian's own renderer. Moving, resizing and reordering preserve complete source code. Mermaid inside existing V2 text layouts keeps its original behavior; new diagram layouts use the V3 media format.

### Mobile touch and editing

- Move diagrams using their top-right grip. For a standalone diagram, hold its body for about half a second, then drag. A quick swipe still scrolls the page; use the frame's corner control to scale a layout.
- Long-press a layout and choose **Edit source** to change diagram code. Standalone diagrams retain their native source button.
- Canceling a gesture writes nothing. One undo restores both the original diagram and its destination layout.
- Fix text caret placement on older Android WebViews, iOS video first frames and inline playback, and unwanted caret jumps after tapping blank layout space.

### Shared fixes

Integrate pane and view synchronization, asynchronous layout readiness, retained video nodes and text editing fixes. Manual text columns, existing image and video layouts, and offline update notes remain available.
