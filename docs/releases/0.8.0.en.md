This update adds mobile support for Android, iPhone and iPad!

It also adds Mermaid diagram support in layouts.

### Arrange Mermaid diagrams like images

Mermaid diagrams can now share layouts with images, videos or other diagrams. Drag, resize and reorder them, or drag a standalone diagram directly into an existing layout.

Try it with the [Mermaid examples](https://raw.githubusercontent.com/Yi-luo-hua/obsidian-adjustable-media/0.8.0/docs/examples/Mermaid.en.md).

### Mobile adaptation and fixes

- Adjust layout button positions and touch controls for easier mobile use.
- Fix mobile text caret placement, input focus and video playback.
- Improve pane and view synchronization, and fix source code flashing when resizing diagrams.
