- **Arrange PDF++ rectangle selections in layouts.** With PDF++ enabled, put crops beside images, resize them, adjust column widths, float the layout, and add captions. In Live Preview, right-click a standalone crop to wrap it or drag it into an existing layout.
- **Edit notes with many PDF++ crops more smoothly.** Live Preview waits until crops in a layout enter the viewport before starting to render them, reducing input stalls.
- **Fix scroll jumps after consecutive floating layouts.** Text stays in place when scrolling past the horizontal rule that follows them.
- **Keep layouts in place while selecting text.** In Live Preview, dragging a text selection across a layout keeps the preview stable. The final selection determines whether the source is shown when you release the mouse button.
