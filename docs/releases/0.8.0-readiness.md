# 0.8.0 发布准备

更新：2026-10-11。当前仅准备本地发布材料，公开版本保持 0.7.3；不合 main、不切换主目录、不推版本标签或创建公开 Release。

## 源码与附件

- 分支：`codex/mobile-release-integration`，代码基线 `3353d63e0c86a8bb7f776f170bf1ba14bf6aee83`，其 461 项检查、生产构建与 [CI](https://github.com/Yi-luo-hua/obsidian-adjustable-media/actions/runs/38152870727) 已通过。本轮只修订发布文档，最终源码提交记录在发布包的 `SOURCE.json` 中。
- 版本：package、manifest、versions 与更新弹窗均为 0.8.0；声明最低 Obsidian 1.5.0，候选 `isDesktopOnly:false`。
- 本地准备目录：主目录忽略路径 `dist/release-prep-0.8.0-20261011/`。`assets/` 只包含 `main.js`、`manifest.json`、`styles.css`，另存生成的 Release 说明、三个文件的 SHA-256、源码来源及安装 ZIP。
- 从最终已提交源码通过 Git archive 导出 LF 文件构建，排除工作树的未入库文件。发布说明由现有生成器产生；安装模板已与移动平台声明对齐。README 继续标注当前公开版，候选说明独立列出。

## 已验收与保留范围

- Windows 专用库：Mermaid、列表归属、关闭清理、双窗格更新、文字栏输入，以及相关拖放／尺寸／撤销场景通过。
- Android 平板 11.5S／Obsidian 1.12.7：图表快测、真人三项清单与报告的正文长按拖入失败场景复测通过，保存内容已核对；输入与视频的基础检查通过。
- Android 手机、iPhone、iPad 的既有基础验收对应各自原构建，详见 [移动记录](../plans/layout-redesign/mobile-adaptation.md)。新增正文长按及边缘投放未在这些设备复测，不能登记为通过；不自动要求重跑原完整清单。
- 三视角其他未验收增量与 PDF 历史场景未在本轮全量重跑，按用户原安排保持范围记录。没有新确认且影响本次交付的阻断缺陷；本地包就绪不等于这些范围全部验收。

## 正式发布时

用户另行授权发布后，固定发布源码并创建 `0.8.0` 标签（不带 v），由标签工作流生成草稿与来源签名，核对三份下载附件、说明和签名后再公开。main 的实现合并、主目录切换与公开版本索引同步分别按用户授权处理，不由本次准备动作代替。详见 [发布流程](../RELEASE.md)。
