# 0.9.3 发布核验

日期：2026-11-02。已正式公开发布 **0.9.3** 并设为最新版本；非草稿、非预发布。UTC 发布时间为 `2026-11-02T05:07:31Z`（北京时间 13:07:31）。

## 范围

- 基于 main `9eda211`，发布 Excalidraw 布局媒体及原生表格右键包装入口。
- Excalidraw 支持并排、图文、环绕、调宽、图注、把手拖入、局部引用与保存／主题变化后的预览刷新，需启用 Excalidraw 插件；详见[功能与验证](../features/excalidraw.md)。
- 表格包装为原有 V2 `type:"text"` 文字布局块，不包含试验阶段的表格媒体项、整表缩放或专属宽高把手。完整原文保留，保留原生菜单，支持一步撤销；详见[表格右键包装](../features/tables.md)。
- 同步版本、锁文件、中英文包内公告与更新弹窗版本，沿用上一版的支持和反馈结尾。最低 Obsidian 版本仍为 1.5.0；表格右键入口依赖 1.6.0 起的 `Menu.forEvent`，旧版仍可使用原有选区包装命令。

## 验证

- 功能阶段：Node 24.11.1 下 534 项测试、类型检查、lint 与生产构建通过。
- 0.9.3 候选：`npm run check` 通过（534 项测试，lint 0 错误）；`npm run release` 仅生成 `main.js`、`manifest.json`、`styles.css`，版本及最低版本映射一致。
- 候选加载至同一测试库：模拟从 0.9.2 升级自动显示中文 0.9.3 公告，同版重载不重复弹窗，手动英文公告正文对应三条更新。测试插件三份文件及设置逐字节恢复，68 份 Markdown／Canvas 笔记 SHA-256 不变，开发控制台未捕获错误。
- Windows 11／Obsidian API 1.14.5／默认主题／Excalidraw 2.29.0：绘图的实时预览、阅读、拖入、取消零写入、一步撤销、源文件保存刷新与局部引用通过；原生表格真实右键包装第二张重复表格、原生菜单保留、原文和一步撤销通过。测试笔记均恢复并核对 SHA-256。
