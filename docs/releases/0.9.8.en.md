- In Live Preview, right-click a media item or the layout frame and select **Edit layout caption** to add a caption below the entire layout. Layout captions can appear alongside individual captions and support Markdown, numbering, alignment, and font size.
- The new **Show layout borders in reading view** setting is off by default.
