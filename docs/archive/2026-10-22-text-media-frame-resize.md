# Issue #34：图文块整体缩放

现象：有文字栏时，把手只调图片栏的 `width`，外框被 CSS 固定为满行。

修复：新增可选 `frameWidth`，只控制整个图文块，保留既有 `width` 的图片栏比例含义。外框侧边／底角调整整体宽度／媒体尺寸，图片栏侧边／底边仍调整栏宽／媒体尺寸。窄图文块支持靠左、居中和靠右；文字保持字号并重新换行。只写开始注释，不改媒体嵌入或文字。

验证：Windows，Obsidian 1.14.4，默认主题，专用 `vml-test-vault`，本分支 0.9.0 开发构建。

- 旧构建实测拖动图片栏底角：外框始终约 708.96px，仅图片栏缩窄。
- 修复后外框可从约 708.96px 缩至 589.14px，图片栏比例 0.4 保留。
- 真实指针操作覆盖右侧、左侧、双侧文字栏及多图行；纯图片块原有缩放通过。
- Esc 取消恢复尺寸、零写入；每次缩放可一步撤销回逐字相同的原文；保存只改变开始注释。
- 同窗格阅读视图与实时预览外框均为 589.14px；阅读视图无编辑把手。
- 外框侧边独立改整体宽度、图片栏侧边保持外框宽度；重载后阅读视图尺寸保留。测试笔记恢复后 SHA-256 与备份一致，再移入系统回收站。
- `npm run check`：505 项测试通过；类型检查、lint 零错误（既有警告保留）。生产构建通过。

未复测用户的 Obsidian 1.12.7、移动端及其他主题。尚未发布新版本。
