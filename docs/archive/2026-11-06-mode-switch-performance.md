# 2026-11-06 模式切换重复测量优化

用户反馈阅读／实时预览切换卡顿。在测试库原笔记上通过 Electron DevTools CPU 采样和实际按钮输入复现，确认两处重复工作：

- 隐藏窗格的宽度变成 0，被 `watchEnvironment` 当成新环境，清掉浮动尺寸；恢复时又失效一次。现在跳过隐藏状态，保留上一次可用环境；真实宽度、主题或字体变化仍更新。
- 滚动定位在输入事件和后续布局事件里反复遍历整篇正文，并对不在视口的文本做字符二分测量。现在仅扫描可见顶层分段，复用仍连接、文本未变的锚点节点；节点替换后重新定位，源码改变后拒绝旧锚点。未改动的笔记也不再因单纯布局通知而重复解析布局标记。
