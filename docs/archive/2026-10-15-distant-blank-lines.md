# 0.8.1 正文连续空行显示修复

日期：2026-10-15。修复基于 `codex/fix-crossref-navigation` 的 `35b2d9e`，已随 0.8.2 正式发布；发布状态与正式附件见 [发布核验](../releases/0.8.2-readiness.md)。

## 原因与改动

在 Windows／Obsidian 1.14.4／默认主题的 `vml-test-vault` 复现：笔记包含布局块时，正文中连续空行从第二行起被标为 `extra`，光标不在该行时 CSS 将高度设成 0。对应行号因此落在相同位置。0.8.1 只对紧邻布局的连续空行豁免，隔着正文段落的空行仍会折叠。

宿主段落解析与退路解析统一把可处理的正文空行标为 `blank`，逐行保留 `--p-spacing`；移除依赖选区隐藏额外空行的装饰和零高度样式。块内部、代码、公式、注释与 frontmatter 保留原有处理，连续浮动之间的一行分隔仍用于并排。阅读视图／PDF 的原生 Markdown 空白规则不变；有多个空行时，实时预览不再追求与这两种输出等高。不改笔记内容或写回路径。

## 验证

- Node 24.11.1：`npm run check` 通过，474 项测试无失败；生产构建通过。回归用例覆盖普通／浮动布局、隔着正文的连续空行与文档首尾，宿主及退路解析均验证 1／3／5 行。
- Windows／Obsidian 1.14.4／默认主题：布局远近的 1／3／5 行均约 16／48／80px，修复前远处三行及五行均只约 16px；修复后没有零高度正文空行或行号叠放。截图已检查。
- DevTools 协议真实 Enter：分别在布局上方、下方隔着正文的段落连续回车三次，输入结果逐字匹配；移开光标后空行高度不变、可见行号位置不重叠。源码／实时预览切换及长笔记滚到底部再回顶部均保留原文和正常空行。
- 文字布局、图文栏、Mermaid、相邻布局前后／块间三行仍约 48px；相邻浮动的一行分隔仍为 0，三行约 48px。`dev:errors` 无捕获错误。
- 生产 `main.js` SHA-256：`9bd2f9a25fdd9978ca8d3d3f5ea4b40523e706dc30deea3f320d6b22c54d6d18`，测试库部署哈希一致。原插件文件、设置与窗格恢复，原笔记逐字及哈希核对，临时测试页移入系统回收站。原始测量、脚本、截图及备份位于忽略目录 `dist/blank-lines-20261015/`。

移动设备、其他主题和 PDF 未在本轮复测，不扩大既有验收范围。
