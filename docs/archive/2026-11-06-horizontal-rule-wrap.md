# 水平线结束布局环绕

用户反馈：只有图片的浮动布局在阅读视图中跨过水平线，水平线缩在图片旁边，下一节继续绕图；实时预览截图中的水平线则位于图片下方。

两种视图的 DOM 和宿主样式不同：阅读视图此前明确把 `hr` 设为 `flow-root`，允许它缩窄排在浮动旁边；实时预览使用编辑器行，当前宿主的水平线类为 `.hr`，既有适配只列出 `.HyperMD-hr`，不能依靠宿主默认样式统一左右浮动的表现。

正文顶层水平线现在使用 `clear: both`，结束此前左右布局的环绕，恢复全宽。实时预览同时识别两种水平线行类，阅读视图与打印使用对应的顶层 `hr` 规则。只改呈现样式，不改笔记、嵌入或布局元数据；布局文字栏内的水平线不应用这条规则。
