# 0.8.0 实时预览把手与连续空行修复

日期：2026-10-14。用户在 Windows 实时预览报告边框外把手被截断，以及布局块前后连续空行只显示一行。本记录对应独立分支 `codex/fix-layout-handles-and-spacing`，基线为 main `692c5d3`；已合入 main 并随 [0.8.1](../releases/0.8.1-readiness.md) 正式发布，标签源码 `b3a7216`；不改变 0.8.0 标签或附件。

## 原因与改动

使用 GitHub 正式 0.8.0 的三份附件，在默认主题的专用 `vml-test-vault` 复现。此前的浮动替身把手修复 `3588622` 仍在 0.8.0 历史中，条件裁剪也保留；本次是普通布局部件的宿主 `contain:paint` 裁掉框外绘制和点击区域。原有防裁剪覆盖浮动／替身，普通布局仅在整篇笔记含有浮动时受保护，没有浮动的笔记仍会截断。两个普通布局的 8 个框外测试点中，7 个无法命中把手。

防裁剪选择器改为覆盖所有直接置于 CodeMirror 正文的插件布局部件与浮动替身，撤掉重复的浮动笔记限定规则。只改变部件的绘制包含方式，原浮动替身的条件 `clip-path` 保留。布局宽高及正文位置不因此改变。

连续空行来自既有段落间距策略：为了接近原生阅读／PDF，首个空行显示 `--p-spacing`，后续空行在非选中状态压成 0。修改宿主段落解析与退路解析：直接接在布局前后的一串空行，每行保留一份段落间距；块内、围栏代码、公式、注释和其他正文的既有规则继续适用。连续浮动之间只空一行时保留原有并排规则，两个及以上空行按作者写出的行数保留高度。

这次连续空行调整作用于实时预览。阅读视图／PDF 继续使用原生 Markdown 的空白规则；不把这个编辑视图修复扩展为其他输出的空白格式改动。
