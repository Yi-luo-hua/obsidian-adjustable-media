# 项目进度与验证记录

更新日期：2026-09-17。

## 发布与开发状态

- 本版为 [0.4.0](https://github.com/Yi-luo-hua/obsidian-adjustable-media/releases/tag/0.4.0)，公开状态和下载附件以 Release 页面为准。插件已在 Obsidian 社区目录中。
- 0.4.0 新增文字块（可浮动、可分 2–4 栏）、块内代码和公式、栏内的图、文字对齐和字号、窄块居中，以及 pandoc-crossref 写法的图表公式编号与交叉引用。
- 0.3.0 包含文字环绕、整块移动、文字栏直接编辑及本轮环绕维护和安全修复；0.2.1 不包含这些功能。
- 发布使用版本标签、GitHub Actions 生产构建、构建来源证明和核验后的 Release 附件。

0.4.0 的验证（2026-09-17，Obsidian 1.13.7，测试库 `vml-test-vault`）：`npm run check` 通过 186 项测试；在 `text-block-test.md` 和 GPT-2 论文前 5 页的复刻笔记里，用 DevTools 协议实测了真实点击、输入、右键菜单和文字设置弹窗，阅读视图与实时预览逐屏对照一致；Obsidian 重启后 MathJax 未加载时打开有编号公式的笔记正常；会改动的测试笔记按备份恢复并核对了哈希。已知限制见 [DESIGN.md 第 1.4 节](DESIGN.md#14-编号与交叉引用)。

0.3.1 修复阅读视图首次添加和移除最后一个环绕布局时旧段落的类同步，并减少 CSS 审核警告。独立复核的双窗格 14 项生命周期检查通过，包含实时预览往返和切换笔记；原有笔记哈希未变。渲染器不可用时的回退仅经静态审查，历史首次滚动跳动仍是已知限制。

## 已完成的修复

- 两个内容相同的布局按当前部件位置定位，可以分别整块拖动。
- 代码、公式、注释和 frontmatter 后的合法落点校验正文目标行，同时保留前一行的原文校验。
- 编辑带别名或尺寸后缀的链接时停止补全，不破坏原有后缀。
- 折叠标题时清理隐藏布局的浮动替身，展开后恢复。

## 本轮验证

环境：Windows、Node 24、Obsidian 1.13.7，专用测试库 `vml-test-vault`。

| 检查 | 结果 |
| --- | --- |
| 从锁文件安装依赖 `npm ci` | 成功，安装时审计报告 0 个漏洞 |
| `npm run check` | 类型检查、官方插件 lint 和 159 项测试通过 |
| `npm run release` | 生产构建及三处版本校验通过，生成三个发布文件，公开状态以 Release 页面为准 |
| 文字栏真实输入 | 输入写回、Alt+B 自定义加粗、旧 Ctrl+B 停用、引用缩进/反缩进、任务切换、括号配对、链接建议和补全、别名保护通过 |
| 输入安全与显示 | 公式/图片显示、中文组字期间不写入、确定后写入、非法块结构拒写、媒体及另一栏原文保留、Esc 退出通过 |
| 阅读视图折叠/展开 | 替身数量 5 → 0 → 5，无编辑手柄 |
| 首次从末尾向上、再向下滚动 | `wrap-multi.md` 两个方向均零检测跳动；`wrap-test.md` 首次向上一次约 31px，下滚零检测跳动 |
| 窄窗格 | 397px 内容宽度下打开多浮动测试笔记、滚到底再返回，段高度均为有限值，无编辑手柄 |
| 插件重新加载 | 成功，无捕获错误 |

滚动检查以 40px 步长比较同一个仍在页面中的段落位置，位移大于 2px 记为一次；这是该测试场景的结果，不代表所有滚动路径均无跳动。测试只使用专用笔记，结束后恢复并以 SHA-256 核对原笔记及快捷键文件。

## 仍需跟踪

- 阅读视图首次虚拟滚动仍可能偶发 24–48px 或约 4–5px 跳动；历史复现条件及尝试见 [DESIGN.md 第 4.1 节](DESIGN.md#41-文字环绕)。本轮多浮动未复现这些跳动，不表示已根治。
- `wrap-test.md` 本轮约 31px 位移与历史记录的首次公式渲染高度变化一致；没有重新做禁用插件的对照实验。
- 链接建议不支持 `^` 块引用和 `[[##` 全库标题；已有别名/尺寸后缀的目标编辑采用保守禁用补全策略。
- 部分快捷键、设置和阅读视图高度依赖 Obsidian 内部接口，读取失败会回退。声明的最低版本仍为 1.5.0，本轮实际只验证 1.13.7；其他版本、第三方主题和平台没有全覆盖。
- 后续版本继续按 [RELEASE.md](RELEASE.md) 执行检查、标签、草稿核验和发布流程。
