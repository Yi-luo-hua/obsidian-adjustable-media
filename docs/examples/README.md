# 示例文档 / Feature Examples

[简体中文](Guide.zh-CN.md) · [English](Guide.en.md)

本目录包含 Adjustable Media 的离线示例笔记与媒体素材，演示多图并排、图文混排、文字环绕、双栏排版、学术交叉引用、手动文字分栏与 Mermaid 独立布局。

This directory contains demonstration notes and bundled media for Adjustable Media, covering side-by-side figures, text beside media, text wrapping, multi-column text, cross-references, manual column breaks, and Mermaid layout items.

## 包含文档

- **综合指南**：[简体中文](Guide.zh-CN.md) · [English](Guide.en.md) —— 在 Obsidian 命令面板运行「功能示例」（`Feature examples`）即可预览或一键在库中创建带素材的示例笔记。
- **手动文字分栏（`+++`）**：[简体中文](ManualColumns.zh-CN.md) · [English](ManualColumns.en.md) —— 可直接复制 Markdown 到笔记中使用（0.7.3 更新弹窗曾内嵌此样例创建入口）。
- **Mermaid 布局示例**：[简体中文](Mermaid.zh-CN.md) · [English](Mermaid.en.md) —— 可直接复制 Markdown 到笔记中使用（0.8.0 更新弹窗曾内嵌此样例创建入口）。

当前版本的「查看更新说明」仅展示当前版本的更新正文，不再提供历史版本的样例按钮；手动分栏与 Mermaid 样例可直接从本目录复制。
