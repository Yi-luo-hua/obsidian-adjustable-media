# Adjustable Media — Agent 排版参考指南

本文档面向直接读写 Obsidian Markdown 笔记的 AI Agent。它只说明 **文本源码格式、精确 JSON 架构、边界规则与常见模板**，不包含鼠标拖拽操作。

> **核心原则**：Adjustable Media 将排版配置保存在 HTML 注释 `<!-- vml ... -->` 与 `<!-- /vml -->` 之间，内部媒体嵌入与 Markdown 正文保持原样。作为 Agent，**修改或生成布局时不得改写用户的原始嵌入链接、别名、尺寸后缀、片段参数或代码块内容**，只需构造或更新规范的注释与块结构。

---

## 1. 块结构与四种模式

每个顶层布局块由 **顶格（第 0 列）** 的开始与结束注释包裹：

```markdown
<!-- vml {JSON} -->
...
<!-- /vml -->
```

若没有任何设置（全默认），开始注释可简写为 `<!-- vml -->`。

### 1.1 四种块类型对比

| 模式 | 版本字段 | 触发条件 | 用途 | 能否浮动环绕（`wrap`） |
| --- | --- | --- | --- | --- |
| **V2 媒体布局** | `"v":2` 或省略 | 块内仅含图片 / 视频 / Excalidraw / PDF 选区行 | 多图并排、网格、单图居中/偏置、图注 | 可以 |
| **V2 图文并排** | `"v":2` | 媒体行之前有文字（左栏）和/或之后有文字（右栏） | 左侧/右侧分析文字配中间媒体 | **不能**（`wrap` 会被忽略） |
| **V2 文字块** | `"v":2`（无媒体行，或设 `"type":"text"`） | 只有文字，或声明 `"type":"text"` | 浮动旁注、2–4 栏自动/手动分栏、表格包装、图文混排 | 可以 |
| **V3 媒体布局** | `"v":3,"kind":"media"` | 含 Mermaid 代码块、`<iframe ...></iframe>` 或 YouTube / X 嵌入 | Mermaid / 网页嵌入与常规媒体混排 | 可以（无侧栏文字时） |

> **例外：Callout 单图缩放**
> 原生 Callout 内的独立图片行不支持完整布局块，但支持带相同 `>` 引用前缀的单图宽度包装：
> ```markdown
> > [!note] 标题
> > <!-- vml {"v":2,"scope":"callout-image","rows":[{"width":0.5}]} -->
> > ![[image.png]]
> > <!-- /vml -->
> ```
> 要求开始注释、图片行、结束注释三行紧邻且具有完全相同的 `>` 前缀。

## 2. 开始注释 JSON 字段完整参考

### 2.1 块级（顶层）字段

所有数值在序列化时保留最多 3 位小数；缺省字段可省略以保持注释精简。

| 字段 | 类型 / 取值 | 默认值 | 说明与约束 |
| --- | --- | --- | --- |
| `v` | `2` \| `3`（省略按 `2`） | `2` | 包含 Mermaid 或网页嵌入时必须为 `3`（且配 `"kind":"media"`）；其他未知版本号会导致整块只读。 |
| `kind` | `"media"` | 无 | 仅当 `v: 3` 时必填。 |
| `scope` | `"callout-image"` | 无 | 仅用于 Callout 内单图宽度设置，不可与通用布局字段混用。 |
| `type` | `"text"` | 无 | 强制整块按文字块处理：块内独立媒体行按文字内嵌图渲染，不触发媒体分栏。 |
| `width` | `number`（`0.2`–`1`） | 占满（环绕或有文字栏时为 `0.4`） | 块占容器宽度的比例（图文并排时表示**媒体栏**占块宽的比例）。手写浮动块时使用 `0.2`–`0.8`，与界面的可调范围一致。手写大于 `0.8` 且小于 `1` 的值时会按原值显示。省略 `width` 即使用默认值。 |
| `frameWidth` | `number`（`0.2`–`1`） | 占满 | 仅用于图文并排块：整个图文外框占容器宽度的比例（独立于 `width`）。 |
| `align` | `"left"` \| `"center"` \| `"right"` | `"left"` | 当块比容器窄且**不环绕**时的水平对齐位置。 |
| `frameOffset` | `number`（`0`–`1`） | 无 | 窄块不环绕时的自由水平偏移（左侧留白占剩余空间的比例）；存在时优先于 `align`。 |
| `wrap` | `"left"` \| `"right"` | 无 | 使媒体块或纯文字块向左/右浮动，让紧随其后的正文环绕。有左右文字栏时无效。 |
| `skip` | `integer`（`1`–`40`） | `0` | 浮动块从当前锚点向下错开的行数；仅在设置 `wrap` 时有效。 |
| `valign` | `"top"` \| `"center"` \| `"bottom"` | `"top"` | 仅用于图文并排块：左右文字栏相对媒体栏的垂直对齐方式。 |
| `cols` | `integer`（`2`–`4`） | `1` | 仅用于文字块：自动平衡分栏数。若块内存在顶格 `+++` 手动分栏标记，`+++` 优先。 |
| `gap` | `number`（`0`–`6`） | `2` | 仅用于分栏文字块：栏间距（单位 `em`）。 |
| `textAlign` | `"left"` \| `"center"` \| `"right"` \| `"justify"` | `"left"` | 文字块与文字栏的文本对齐方式（支持两端对齐 `justify`）。 |
| `size` | `number`（`0.5`–`2`，不为 `1`） | `1` | 布局块内文字相对正文的字号倍数。 |
| `caption` | `{ text, align?, scale? }` | 无 | 整组布局底部的总图注：`text` 为非空 Markdown 字符串；`align` 为 `"center"`（默认）或 `"left"`；`scale` 可选 `1.25`、`1.5`、`2`。 |
| `rows` | `RowMeta[]` | `[]` | 按媒体行顺序对应的行设置数组（文字行不计入索引）。 |

### 2.2 行级字段（`rows[i]`）

| 字段 | 适用 | 类型 / 取值 | 默认值 | 说明与约束 |
| --- | --- | --- | --- | --- |
| `items` | V3 行 | 正整数 | 按源码物理行 | 该逻辑行包含的媒体项数（建议最多 `4`）。**只要任意一行写了 `items`，所有行都必须提供正整数 `items`，且总和必须严格等于块内媒体项总数**，否则整块报错变为只读。 |
| `heights` | V3 网页行 | `(number \| null)[]` | 继承行高 | 数组长度必须等于该行媒体项数；数值范围为 `80`–`900`（px），`null` 表示继承行高或 iframe 原高度。 |
| `height` | 所有媒体行 | `number`（`80`–`900`） | `220` | 该行媒体高度（px，解析时四舍五入并截断到 `80`–`900`）。 |
| `widths` | 多项行 | `number[]`（正数） | 等宽 / 按比例 | 按项对应的列宽权重（如 `[1.2, 0.8]`）；长度必须等于该行媒体项数。 |
| `width` | 单项行 | `number`（`0.1`–`1`） | 原尺寸/占满 | 单项占当前行宽的比例；多项行中忽略。 |
| `align` | 单项行 | `"left"` \| `"center"` \| `"right"` | `"center"` | 单项在行内的水平对齐；多项行中忽略。 |
| `offset` | 单项行 | `number`（`0`–`1`） | 无 | 单项在行内的自由水平位置（左侧空白占行内剩余空白的比例）；优先于 `align`。 |
| `captions` | 所有媒体行 | `(string \| null)[]` | 无 | 每项图注的 Markdown 文本；长度必须等于该行媒体项数，无图注填 `null`。 |
| `captionAlign` | 所有媒体行 | `"left"` \| `"center"` | `"left"` | 该行图注的对齐方式。 |
| `captionScales` | 所有媒体行 | `(1.25 \| 1.5 \| 2 \| null)[]` | 默认字号 | 每项图注的字号倍率；长度必须等于该行媒体项数。 |

### 2.3 JSON 字符转义规则（必须遵守）

开始注释是单行 HTML 注释，以下两个字符在 JSON 字符串值中**必须转义**，否则 Obsidian 或 HTML 解析器会截断布局块：
1. `--` 必须写成 `-\u002d`（防止出现 `-->` 提前闭合注释）。
2. `%` 必须写成 `\u0025`（防止出现奇数个 `%%` 使整行被 Obsidian 当作隐藏注释）。

## 3. 媒体识别规则与行尾标记

插件只将 **非空且整行仅包含合法媒体嵌入** 的顶层文本行识别为媒体行（每行建议不超过 4 项）：

| 媒体类型 | 识别语法与条件 | V2 / V3 | 特殊要求 |
| --- | --- | --- | --- |
| **本地图片 / 视频** | `![[file.png]]`、`![alt](path/a.webp)`；图片支持 `avif/bmp/gif/jpeg/jpg/png/svg/webp`，视频支持 `mkv/mov/mp4/ogv/webm` | V2 / V3 | 同行多图用空格分隔；V2 每行即一行布局。 |
| **标准扩展名外链图片** | `![alt](https://example.com/a.png)` | V2 / V3 | URL 路径以常见图片扩展名结尾时自动识别。 |
| **无扩展名外链图片** | `![alt](https://example.com/img?id=1)` | V2 / V3 | 必须在**该媒体行末尾**附加标记 ` <!-- vml-image-row -->`，否则会被当作普通文字。 |
| **Excalidraw 绘图** | 本地 `.excalidraw` 或 `.excalidraw.md`（支持 `#group=...`、`#area=...` 片段） | V2 / V3 | 需用户启用 Excalidraw 插件；普通 `.md` 笔记不接管。 |
| **PDF++ 矩形选区** | `![[doc.pdf#page=7&rect=45,120,500,600\|说明]]`（`page >= 1` 且 4 个有效非零面积坐标） | V2 / V3 | 在含 PDF++ 选区的**每个媒体行末尾**加上 ` <!-- vml-pdf-row -->`，仅含 PDF++ 选区的 V3 块也需要标记。仅当旧格式 V2 块全由无标记的 PDF++ 选区组成时，才可省略标记。 |
| **Mermaid 图表** | 完整 ` ```mermaid ... ``` `（或 `~~~mermaid`）围栏 | **必须 V3** | 每个完整围栏独立占行作为一个媒体项，用 `rows[i].items` 编排同行数量。 |
| **网页嵌入** | 完整 HTTP/HTTPS `<iframe ...></iframe>`（禁 `srcdoc`），或原生 `![](YouTube/youtu.be/twitter.com/x.com status URL)` | **必须 V3** | **每个 `</iframe>` 行后面必须紧跟至少一个空行**，防止后续 Markdown 或 `<!-- /vml -->` 被吞进原生 HTML 块。 |

## 4. 文字栏、手动分栏与正文环绕规则

### 4.1 强制失效边界（Agent 生成前必须自检）

1. **禁止在媒体行之间插入文字**：在未设置 `"type":"text"` 的块中，第一行媒体之前的文字属于左栏，最后一行媒体之后的文字属于右栏；若两行媒体之间出现文字，**整块判定为无效**并被插件完全忽略。需要在文字间穿插图片时，务必设置 `"type":"text"`。
2. **禁止空块**：没有媒体也没有非空文字的块不会被接管。
3. **禁止未闭合结构**：块内的代码围栏（` ``` `）、数学块（`$$`）或 HTML/Obsidian 注释（`<!--`、`%%`）必须闭合，否则插件读不到 `<!-- /vml -->`。
4. **列表结尾必须留空行**：当文字栏或文字块以列表（`- `、`1. `）结尾时，**在列表与 `<!-- /vml -->` 之间必须保留一个空行**，否则 Obsidian 阅读视图会把结束注释及后文吞入列表最后一项。
5. **不能嵌套或放在缩进/引用内**：完整布局块必须从正文第 0 列开始，不能放在列表、引用或 Callout 内部（Callout 内仅支持 `scope:"callout-image"` 单图缩放）。
6. **图文并排不可浮动**：只要块内同时有媒体和左右文字栏，`wrap` 与 `skip` 都会失效（仅纯媒体块或纯文字块可设 `wrap`）。

### 4.2 手动文字分栏（`+++`）

在文字块（无媒体行，或 `"type":"text"`）中，将 `+++` **顶格独占一行** 写入正文即可手动换栏：
- 最多支持 **4 栏**（即最多 3 个 `+++`）；超过 3 个会触发告警并回退为自动 `cols` 分栏。
- 各栏等宽、顶部对齐；连续写两个 `+++` 可留出空栏。
- 若上一行是列表或引用，先留一个空行再顶格写 `+++`。
- 代码块、公式、注释或缩进内的 `+++` 不会被解析为分栏标记。

### 4.3 正文环绕与结束环绕

- 将带 `"wrap":"left"` 或 `"wrap":"right"` 的块**紧贴写在被环绕段落的正上方**（也可按需用 `"skip": N` 向下错开 N 行）。
- 在正文顶格写一条 Markdown 分隔线 `---` 即可立即结束上方所有的左右环绕，使后续正文恢复全宽排版。

## 5. 学术编号与交叉引用（pandoc-crossref 语法）

- **图注编号**：在图注文本末尾（块内 `captions`、`caption.text` 或正文独立图注段）加 `{#fig:标签}`。
- **表注编号**：在表格紧邻的说明段落末尾加 `{#tbl:标签}`。
- **公式编号**：在 `$$ ... $$` 公式块内加 `\label{eq:标签}`（若公式已手写 `\tag` / `\notag` / `\nonumber`，插件只移除 `\label`，不再重复加号）。
- **正文引用**：使用 `@fig:标签`、`@tbl:标签`、`@eq:标签`（会自动渲染为“图 1 / Figure 1”、“表 1 / Table 1”、“式 (1) / Eq. (1)”并支持点击跳转；找不到标签时显示红色 `??`）。
- **标签命名约束**：标签主体匹配 `[A-Za-z0-9_][\w.:-]*[\w-]|[A-Za-z0-9_]`，**不能以 `.` 或 `:` 结尾**（句末标点会被留在外侧）。同一标签重复定义时仅首次生效。
- **JSON 图注标签**：避免连续的连字符（`--`），例如使用 `fig:loss-curve`。`rows[].captions` 或 `caption.text` 中的 `--` 按要求转义后，交叉引用索引将无法识别该标签。

## 6. 可直接复用的标准模板

### 模板 A：两图并排 + 比例 + 单项与整组图注
```markdown
<!-- vml {"v":2,"caption":{"text":"实验结果总览","align":"center"},"rows":[{"height":220,"widths":[1.2,0.8],"captions":["准确率对比 {#fig:acc}","消融实验 {#fig:abl}"],"captionScales":[null,1.25]}]} -->
![[acc.png]] ![[ablation.png]]
<!-- /vml -->
```

### 模板 B：图文并排（左图右文 / 左文右图）
```markdown
<!-- vml {"v":2,"width":0.45,"frameWidth":0.9,"align":"center","valign":"center"} -->
![[arch.png]]
### 模型结构
这里位于图片右侧。若把这段文字移到图片行上方，则显示在图片左侧。

- 列表结尾必须留空行

<!-- /vml -->
```

### 模板 C：右浮动文字旁注 + 结束环绕分隔线
```markdown
<!-- vml {"v":2,"width":0.32,"wrap":"right","size":0.9} -->
**关键参数**
- Learning rate: `3e-4`
- Batch size: `64`

<!-- /vml -->
这段正文将在左侧环绕上方卡片排版。如果需要在某处提前恢复全宽排版，在下一段前加上顶格的 `---` 即可。

---
```

### 模板 D：手动多栏文字块（`+++`）
```markdown
<!-- vml {"v":2,"type":"text","gap":1.5,"textAlign":"justify"} -->
### 方案 A
- 优点一
- 优点二

+++

### 方案 B
这里可以自由编写右栏内容，甚至内嵌参考图：

![[diagram.png]]
<!-- /vml -->
```

### 模板 E：V3 Mermaid 与网页嵌入并排
````markdown
<!-- vml {"v":3,"kind":"media","rows":[{"items":2,"height":240,"widths":[1,1.2],"heights":[null,280]}]} -->
```mermaid
flowchart LR
    A[输入] --> B[处理] --> C[输出]
```
<iframe src="https://www.openstreetmap.org/export/embed.html?bbox=-0.16%2C51.49%2C-0.10%2C51.52" title="Map"></iframe>

<!-- /vml -->
````

### 模板 F：PDF++ 矩形选区与无扩展名外链图混排
```markdown
<!-- vml {"v":2,"rows":[{"height":220,"widths":[1,1]}]} -->
![[paper.pdf#page=3&rect=50,400,540,720|Fig 1]] ![外链图](https://example.com/render?id=42) <!-- vml-image-row --> <!-- vml-pdf-row -->
<!-- /vml -->
```

### 模板 G：Callout 内单图缩放
```markdown
> [!info] 结构示意
> <!-- vml {"v":2,"scope":"callout-image","rows":[{"width":0.5}]} -->
> ![[diagram.png]]
> <!-- /vml -->
```
