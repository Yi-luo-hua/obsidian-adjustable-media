# 网页嵌入：把资料和笔记放在一起

边看课程边记重点，把两张地图放在一起比较，或把参考网页留在正文旁边。网页可以直接操作，笔记也有自己的位置。

> [!tip] 先看，再动手
> 阅读视图看排版，切到**实时预览**试着调整。以下示例无需本地素材；网页内容需要联网。

**我的安排：**每天只选一个主要区域；出发前补上预约时间、交通方式和雨天备选。

## 2. 学习记录：视频旁边，直接写笔记

适合在线课程、软件演示和论文讲解：一侧保留播放器，另一侧写自己的理解，不必来回切换页面。

写游记或实地调查记录时，把地图留在页边，正文用来整理路线、现场观察和下一次要确认的问题。

这里的文字是笔记本身的正文，会随输入绕过右侧地图。写到地图下方后，文字自然恢复整行宽度。

**试一试：**右键地图的组件把手，切换靠左／靠右环绕；拖动整个布局顶部的把手，把这份参考资料移到对应段落旁边。

## 自己做一份：三个步骤

1. **获取嵌入。**在网站的「分享 → 嵌入 / Embed」中复制完整的 `<iframe …></iframe>`，粘到笔记正文，前后各留一个空行。YouTube 视频也可写成 `![](视频网址)`。粘贴内容不要放进代码块。
2. **放进布局。**实时预览中，点击网页右上角的把手，选择「包成布局块」；已有布局时，直接拖动把手，把网页放到另一项旁边或新的一行。也可选中完整嵌入，执行「把选中的内容包成布局块」。
3. **调整与移出。**拖动分隔线调宽、网页底边调独立高度；点击或右键组件把手，选择「移出布局块」放回正文。移出后还能拖回布局。

**现在练一次：**把第一组中的巴黎地图移出布局，再从它右上角的把手拖回伦敦地图旁边。每次操作都可以单独撤销；拖动途中按 `Esc` 取消。

点击把手打开菜单，再点同一把手或其他位置关闭。**排版用外部把手，网页内部照常操作。**
