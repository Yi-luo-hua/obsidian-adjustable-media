# PR #20 段落间距修复

2026-10-08 修复私密审查确认的两个 P2 问题：

- 宿主确认的标题同时识别 ATX 与 Setext 形式。Setext H1 的下方、所有标题的上方保留标题自身的间距策略，空行和紧邻分块都遵循同一规则。
- 链接引用定义没有可见盒子。连续的定义不重复生成段落间距，只在两侧可见分块之间按原有标题规则生成一次；定义也不能作为浮动锚点两侧的正文。

生产代码只修改 `src/markdown/paragraphBreaks.ts`，不改变笔记写入和异步解析队列。
