## W10 输入入口

- 移动端文字栏提供“完成”和“放弃草稿”按钮，44px 最小高度，窄栏允许换行。电脑保持原来的输入界面。
- “完成”在 CodeMirror 仍报告组字时不退出、不写回候选；输入法确定后按现有写入规则结束。合法文字仍随输入写回，保留原生历史。
- “放弃草稿”仅在存在未保存的无效文字时可用，丢弃草稿并重新显示笔记当前内容；不撤回已经保存的输入，也不改媒体或另一栏。已保存的内容使用原生撤销恢复。
- 单元测试覆盖组字时完成零写入、确定后写回与关闭、无效草稿放弃零写入和不再恢复。真实触摸／键盘遮挡仍待恢复测试。
- 暂停之前的 Windows 辅助界面探针有未通过断言，历史见 `w10-input-actions-before-resume.json`；初轮测试类被 CodeMirror 覆盖的运行另存为 `w10-input-actions-harness-class-reset.json`。本记录当时没有重跑；恢复后已补验收，当前 `w10-input-actions.json` 是 24 的最新生产构建回归，不能再用它表示暂停时的失败结果。

## W02 源码阶段

新增纯模块 `src/layout/candidateDocument.ts`，先用运行期身份绑定实际 `BlockEdit`，再通过与编辑器／文件写入相同的规则，在内存应用修改，重新解析最终源码。

- 文件候选遵守 CRLF 和未修改行原文；编辑候选使用真实提交的 offset changes。
- 测量输入来自设置取整之后的实际源码，例如 1/3 宽度写入并读回为 0.333；移动候选中旧位置已经移除，不让旧浮动占位参与后续关系。
- 每份候选使用独立 lineage，不替换发起窗格的当前快照；结果状态只叫 `parsed`，不标 `ready`。写入仍走现有 writeBack，本模块不写文件。
- 语义检查覆盖取整、CRLF、编辑事务一致、EOF／skip=40、同侧／异侧三浮动、重复实例定位、旧依赖／重叠拒绝、未知格式和代码围栏保护。
- `scripts/prepare-candidate-prototype.mjs` 生成七个源文候选，证据为 `probes/w02-source-candidates.json`。这不是几何／预算验收。
- 待恢复测试：受限真实宿主副本与前向测量比较、候选实际 measurementSpec、内容／环境／资源版本匹配、提交及关闭重开后边界 ≤2px。移动时改变设置后的目标身份对应仍须在 W03 契约冻结前明确；当前 detached 重新解析不承诺跨候选的块 ID 稳定。
