## 实测发现与修复

1. **渲染已结束，状态仍 measuring。** 调整宽度／字体／主题和热打开后，Markdown 异步渲染与浮动测量完成没有唤醒投影确认，直到下一次输入／滚动才推进。现在 Markdown 渲染结束发出只用于重新测量的事件；浮动尺寸／间隔测量结束也通知窗格。失败的 Markdown 仍保持 failed，不把通知当作成功测量。
2. **删除最后一个块后旧令牌仍有效。** 现在源快照消失时清空投影版本、coverage 与令牌；相同窗格随后仍能接受新的布局快照。快照变化也直接触发确认，不等几何事件。
3. **首次打开长浮动中段时 pending 状态残留。** 原锚点在 Markdown 尚未完成时记录了尺寸与 pending；随后替身虽然完成渲染，旧尺寸被当成已确定的锚点尺寸，pending 未被清除。现在替身读回就绪后更新这份尺寸并清除 pending；替身未就绪时继续 pending。

源码变化不生成任何笔记写入。完成通知不改变环境 epoch，也不通过周期性重绘让状态收敛。
