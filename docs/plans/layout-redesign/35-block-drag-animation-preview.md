## 1. 设置与范围

| 项目 | 约定 |
| --- | --- |
| 中文名称 | 拖动布局块动画效果（保持用户指定名称） |
| 英文名称 | Layout block drag animations |
| 类型／默认值 | 布尔开关，默认 `true`；旧配置缺少该字段时按开启处理 |
| 保存位置 | 插件设置；不写入笔记、布局注释或持久化格式 |

| 关闭 | 停止物理与过渡动画，保留准确的静态放置预览、合法落点提示和同一套规划／写回规则 |
| 系统减少动态效果 | 保留用户开关值，按系统偏好抑制惯性／回弹等明显运动，保留静态有效预览 |
| 首版入口 | 实时预览中从块手柄发起的整块拖动；桌面鼠标与后续移动触摸共用设置及核心 |

设置说明须写中文与英文，放入 `src/view/messages.ts`，使用句首大写。候选设置字段可采用 `layoutBlockDragAnimations`，实现时与现有设置命名统一。不顺带改变内部媒体重排、缩放和文字栏编辑的动画行为；阅读视图与 PDF 沿用已有展示入口，首次手机支持仍按 W09–W11 验收。

关闭设置时停止正在播放的效果并切回静态呈现，不触发笔记写回；重新开启后从下一次整块拖动使用动画。动画开关不改变同一有效操作的最终源码、实例对应、落点、撤销次数或取消结果。

## 2. 用户看到的效果

1. **拿起**：块轻微放大并浮起，增加阴影，保持指针／手指相对抓取点的位置。
2. **拖动**：替身持续跟随指针，带有轻微惯性感和弹性；参数优先保证易于定位，在真实鼠标／触摸操作中调试。
3. **经过落点**：根据最新有效计划展示放置效果，相关布局块平滑让位，普通正文显示真实的换行与环绕变化，必要时显示下移／吸附原因。
4. **松手**：锁定已经确认的合法最终落点，块弹性吸附到该位置；相关块与正文过渡到同一计划的实际排版。
5. **取消**：未提交时恢复原呈现并清理预览；已经成功提交后的过渡被打断时只停止效果，保留真实提交，撤销沿用原生历史。

预览范围包含移动块、受影响的其他布局块及源位置／目标位置附近的正文。文字重新换行由实际候选排版提供；不能用平移旧段落、缩放旧高度或单个落点框冒充完整放置预览。正文重排可采用真实候选内容切换配合短暂淡入，避免把每个文字片段作为独立物理对象。

## 3. 最终排版与动画的关系

- W03 输出可由现有 V2 源位置、wrap、skip 等字段还原的最终计划；预览、菜单与提交消费同一份经过读回和测量验证的结果。
- 动画使用只读的视觉呈现层，按已确认目标播放；不靠动画坐标改写真实编辑器的正文流或源位置，不干扰宿主测量与命中。
- `measuring` 时可展示即时跟手替身、候选落点和测量状态；尚未确认的排版不能标为 ready。迟到的旧候选不能替换当前预览。
- pointerup 吸收最后指针位置并冻结最终序号；只有当前 ready 且版本有效才经 `writeBack.ts` 一次提交。仍 measuring／blocked／过期时零写入，不在松手后等动画或资源完成再偷偷提交。
- 采用有惯性感的跟随与吸附，松手后的动画不继续寻找新落点。本轮不加入按速度自由甩动并改变最终位置的行为。
- Esc、pointercancel、丢失捕获、切换文件／模式、实例消失、插件卸载及窗格关闭释放动画、预览和异步回调。动画结束不会生成第二次写入或新的历史步骤。
- 视频／音频预览使用静态封面或可用的静态呈现，保留真实播放器，避免复制出自动播放、交互监听或重启原播放器的副本。

沿用已确认的 **测量副本测完即销毁** 约定。手势期间的轻量预览只保存必要的已确认呈现和数据，结束即清理；不借动画改成每窗格常驻、提前预热的宿主副本。

## 4. 工作安排

| 阶段 | 工作 | 依赖／完成条件 |
| --- | --- | --- |
| W03：完整放置计划与预览数据 | 补真实边距／正文流，求出源顺序、碰撞、正文余宽、skip 上限与 EOF 的可实现结果；包含相关块、正文及源／目标区域 | 当前纯约束基础继续推进；最终源码读回和同一版本测量完成，ready 与提交／重开匹配 |
| W04：默认开启的设置与动画 | 接入设置和旧配置兼容；拿起、跟随、邻块让位、吸附与正文过渡；静态模式、减少动态效果及生命周期清理 | W03 有效计划可用，真实鼠标手势及开／关对照通过 |
| W11：触摸接入 | 在同一规则上验证手指跟随、边缘滚动、取消及系统中断，按实际设备表现调整参数 | W10 与 W03／W04 相应门槛具备；按受影响平台定向验证 |
| W05：集成与性能 | 比较动画预览、静态预览与实际提交；大笔记、快速替换、历史、资源及窗口清理 | 保留当前性能口径和峰值记录，不把普通增量扩成每次全设备回归 |

先完成可靠的完整放置预览，再加动画过渡。每帧合并到最新指针与有效候选，复用同环境的有效结果；缩小范围必须有影响结束证明，不在每次移动时重测整篇。跟手效果与异步测量分开调度，动画不会让未完成的计划变成可提交。

- [ ] 三块及更多、同侧／异侧、长浮动、文字环绕、重复块、EOF 与源码展开，预览包含实际受影响的块和正文；同环境 ready 与提交／重开各边误差不超过 2 CSS px。

- [ ] 拿起、跟随、让位、吸附和取消在真实手势中观察；减少动态效果、切页／关窗／重载及视频预览无遗留、无重复播放。
- [ ] 200 块／约 1 万行场景按受影响范围增量测量；纯计算 p95≤8ms、测量／应用回调同帧累计 p95≤16ms。动画启用时把动画回调也计入同帧累计，另列动画开销、冷预览延迟、峰值与 ≥50ms 长任务并继续优化。
